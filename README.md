# tikita-creator-workflow

Tikita 創作工作流 skill。
作者：到雫個公園睡覺（@Starlease／@na_daily.0714）

最新版本與下載：[Releases](https://github.com/na-daily/-/releases/latest)｜[更新紀錄](CHANGELOG.md)

## 這是什麼
給 AI 用的一套做法：透過 Tikita 官方 MCP 讀你建好的故事草稿，幫你構思、寫、整理，再把內容寫回草稿。它寫的是給模型扮演用的設定，不是資料建檔。

## 它能做什麼
**寫**
- 作品設定與世界觀：世界、各項規則、變數、文風
- 角色卡：公開卡與私設，從經歷寫到心境與傾向；你用標籤描述性格（傲嬌、毒舌、病嬌）時，會先分清是哪一種再寫
- 開場、起手式、標題與標語、介紹頁
- 章節：之後才揭開的內容、會反覆用的流程、一次性的事件、開局
- 設定集：沒有角色卡的角色、物品、地點、補充細節

**變數與狀態面板**
- 先分清哪些不需要變數、哪些玩家不需要知道、哪些給玩家看
- 把同一個角色、名單或一個地點的狀態合併成文字變數
- 倒數、累計、狀態切換、排程與待辦、定期與隨機事件的寫法
- 狀態面板的 HTML

**整理既有的草稿**
- 找出同一件事寫在兩處以上的地方，列給你確認再整理
- 照你原本的格式整理，不換成它自己的格式
- 一則回覆做不到的規則改寫成做得到的，變數留著
- 字數超過上限時，告訴你哪些可以搬到設定集或章節

**平台規則**
- 欄位上限、30,000 字預算、發布條件
- 分級與審查標準、公開區的用語
- 成人向作品的寫法
- 圖庫的上傳與分組

## 它不會做的事
- 不發布、不刪除作品
- 不自行刪掉或合併你做好的變數、角色、章節、設定集條目
- 不代你發留言
- 不執行付費生圖
- 草稿要你在 Studio 存檔才生效，測試對話也要你自己開

## 使用前
需要先在你使用的 AI 工具裡接上 Tikita 官方 MCP。

## 取得與安裝
1. 到 [Releases 最新版](https://github.com/na-daily/-/releases/latest) 下載 `tikita-creator-workflow-版本號.zip`。
2. 在你的 AI 工具的 skill 設定裡上傳這個 zip；用資料夾載入 skill 的工具則解壓縮後把 `tikita-creator-workflow` 資料夾放進 skill 目錄。

## 怎麼用
先在 Tikita Studio 建好一個故事草稿，把草稿的網址或 short_id 給 AI，再說你要做什麼，例如：
- 「幫我把這個角色寫成角色卡」，附上你的設定
- 「整理這份草稿，看有沒有重複的地方」
- 「變數交給你」

說「交給你」時它會先問範圍（全部、角色卡、作品設定、變數、面板、介紹頁），範圍內直接整理，做完回報。

## 檔案
內容在 [`tikita-creator-workflow/`](tikita-creator-workflow) 資料夾：
- `SKILL.md`：流程、每件事寫在哪、依任務讀哪幾份
- `references/writing-rules.md`：每次動筆都要讀的規則
- `references/` 其他檔案：角色卡、文風、變數、章節、世界觀與設定集、開場與公開區、平台規則、工具、分級與審查、狀態面板、性格標籤

想看某個檔案每次的差異，點進檔案後按 **History**。
