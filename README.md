# tikita-creator-workflow

Tikita 創作工作流 skill。
作者：到雫個公園睡覺（@Starlease／@na_daily.0714）

目前版本：**v19**（見 [`version.txt`](version.txt)）｜[更新紀錄](CHANGELOG.md)

## 這是什麼
透過 Tikita 官方 MCP 構思、寫角、把內容寫進故事草稿用的 skill。內容在 [`tikita-creator-workflow/`](tikita-creator-workflow) 資料夾：

- `SKILL.md`：流程、每件事寫在哪、依任務讀哪份
- `references/`：各主題的寫法與平台規則

## 使用前
需要先在你使用的 AI 工具裡接上 Tikita 官方 MCP。

## 取得與安裝
1. 這頁右上角 **Code → Download ZIP** 下載並解壓縮。
2. 取出裡面的 `tikita-creator-workflow` 資料夾（只要這個資料夾，不含外層的 README 等檔案）。
3. 把這個資料夾壓成 zip，在你的 AI 工具的 skill 設定裡上傳；用資料夾載入 skill 的工具則直接把資料夾放進 skill 目錄。

## 更新
更新時整個資料夾換成新版即可。改了什麼看 [更新紀錄](CHANGELOG.md)；想看某個檔案每次的差異，點進檔案後按 **History**。

## 注意
僅提供給收到連結的人使用，請不要轉貼連結或轉載內容。
