# 敘事指示：作品設定的「運作與敘事」
> 這套工作流的做法，非官方。

敘事指示是寫進作品設定（`detailMd`）、要模型每一則回覆照做的句子。在 Tikita，人稱、長度、節奏、文風全部由作品決定。使用者的材料裡已經有敘事的寫法時，照他的寫法與格式整理；其餘情況照這一頁一次寫完。

## 一次寫完
1. **先確認作品的主題**：題材、{{user}} 和角色是什麼關係、玩家在裡面主要做什麼、是不是成人向。材料裡有的直接用。
2. **照主題把下面每一樣定好**，連同「照作品加的小節」，一次寫成完整的一塊。
3. **交稿時列出定了什麼**：文風、人稱、長度、節奏各是什麼，加了哪幾個小節、哪幾個留著沒加。一樣一句，使用者要換再換。

## 句子怎麼寫
1. **每一句寫的是這三種之一**：世界怎麼運作、角色是什麼樣的人、文字寫成什麼樣子。模型會把句子照字面演出來，所以每一句都寫成事實。
2. **回覆怎麼收尾交給開場示範**，開場收在哪種地方，模型就收在哪種地方。
3. **會發生的事件寫在世界觀或章節**，由那裡的條件帶出來；敘事指示只留平常怎麼運作。
4. **句子寫成正文要有的結果**。模型的思考過程在 Tikita 會直接印給玩家看，所以寫「正文是什麼樣子」。
5. **每一樣寫一次**。整段連同小節以一千字左右為參考，超過時先刪再加。

寫好後照這張表對一次，右邊的說法會被模型照字面演成左邊的結果，遇到就改寫成上面第 1 條的三種之一：

| 模型會演成 | 來自這種句子 |
|---|---|
| 結尾出現「等著你的回應」這類鉤子 | 停在方便 {{user}} 回應的地方、留鉤子、引導玩家 |
| 角色每一則硬找事做 | 主動推進劇情、主動 |
| 每回合出事 | 張力、衝突、陰謀、意外、危機、發生事情 |
| 連 {{user}} 已有的外貌與衣著都略過 | 只寫 {{char}} 這一側 |

## 每部作品都有的
這四句照用。講的是所有角色，用沒有數字的 `{{char}}`。
```
- 這個世界不是圍繞著 {{user}} 運作的，任何角色依然照自己的工作與作息過日子。
- {{char}} 有自己想做的事和自己的判斷，只依親眼看到、親耳聽到和本來就知道的事行動。他做的事接著前一件事來；場面平靜時照日常的步調寫。
- 細化情境描寫：當前所在的場景（季節、溫差、光線等）、感官、動作的過渡，以及人物的外貌與表情。
- 每一句都寫出主詞，不省略。台詞一段只放一到兩句，話多就拆成好幾段，每段另起一行並標上說話的人。
```

## 照主題定的
每一樣照這部作品的主題定，各寫成一句，接在上面四句後面。

**文風**
1. 第一句寫類型：「以（類型）的寫法敘事。」類型照第 1 步確認的主題填，用你知道的小說或故事類型裡最接近的那一種，名字用通用的叫法。
2. 使用者的材料裡有他自己寫的開場或段落時，再加一句，寫從那段文字直接看得到的特徵：句子長還是短、對話多還是描寫多、用詞口語還是書面、筆墨花在心理還是動作。
3. 材料裡只有設定、沒有他自己寫的段落時，只寫第一句，並在交稿時說明文風只定了類型。

**旁白視角**
- 預設第二人稱：「以第二人稱「你」稱呼 {{user}}。」
- 群像、{{user}} 常常離場的作品用第三人稱：「以第三人稱敘事，{{user}} 用名字稱呼。」
- 只有一個主要角色、看點在他怎麼想的作品可以用角色的第一人稱：「旁白用 {{char}} 的第一人稱「我」敘述，只寫他看得到、想得到的事。」

**回覆長度**
- 預設：「每則回覆以 {{user}} 這一則寫的方向為主軸，做細膩的擴寫。」
- 傳訊息、直播聊天室這類一來一往很快的作品：「每則回覆寫一個動作或一段對話。」
- 長度用句子定，並跟著開場本身的長度走。使用者明說要字數範圍時，把字數接在這一句後面。

**節奏**
只有這兩種作品加一句，其餘作品照預設。
- 慢熱、日常、重相處過程的作品：「一則回覆只寫當下這一小段時間，中間的過程都寫出來。」
- 經營、任務、模擬器這類一則要過很多事的作品：「一則回覆可以跨過一段時間，瑣碎的過程一句帶過。」

**對話和描寫的比重**
通常已經含在文風那一句裡。文風那一句只有類型時，照作品補一句：「以對話為主，動作與環境用一兩句帶過。」或「以動作與情境描寫為主，台詞少而短。」

**固定畫面**
回覆裡要排固定畫面的作品（平台介面、彈幕、系統視窗），加一句寫畫面版型放在回覆的哪裡，用程式碼區塊排。

作品的語言由開場和設定本身的文字帶。機制什麼時候觸發寫在世界觀或變數說明。

寫出來的骨架：
```
## 運作與敘事
- （每部作品都有的四句）
- （文風：一到兩句）
- （旁白視角：一句）
- （回覆長度：一句）
- （節奏、比重、固定畫面：用得到才有）
```

整理既有作品時，講同一件事的舊句整句換成對應的那一句，作品自己特有的寫法留著。舊句裡有字數規定時，問使用者要留著還是換成擴寫那一句。

## 照作品加的小節
照作品判斷，用得到的直接加。

### 內心的寫法
照作品挑一種；三種都對不上時留空，寫多少感受就跟著開場的示範走。
- 看點在角色心裡怎麼想的作品（偏執、陰濕、表裡不一）用第一句。
- 使用者自己的格式本來就有獨立的內心話時用第二句。
- 懸疑、互相隱瞞、要讓玩家自己猜的作品用第三句。
```
- 事情讓角色的情緒有明顯起伏時，直接寫出他的感受。
```
```
- 角色心裡的想法、感受與心聲寫在引用另起一行的內心話裡，情緒起伏越大，心裡的話越多。
```
```
- 旁白只寫從外面看得出來的事：角色心裡的想法只有他自己知道，情緒從他的動作與神情裡讀出來，旁人可能誤解、可能錯過。
```

### 關係與認知
放在作品設定「各項規則」底下；作品設定裡還沒有那一節時放「運作與敘事」。

關係怎麼確認（戀愛向作品都加；有好感數值或關係階段的作品一定要加）：
```
- 好感高代表 {{char}} 在意 {{user}}。{{char}} 喜歡上一個人時，會照自己的性格讓對方知道；想交往、想結婚也是他自己會提的事。兩人成為戀人，是在告白並得到 {{user}} 回應的時候；在那之前發生的親密，關係照原樣。
```
- 這一句讓模型在第一次親密之後繼續照原本的關係演，也讓角色自己會表示。句子只寫他喜歡上人時是什麼樣子。
- 他會怎麼告白、送哪一類東西，寫在角色卡「與 {{user}}」，照他的性格寫傾向，只給類別。告白、求婚有專屬章節的作品，章節寫「由他開口時」與「{{user}} 先開口時」兩種。

玩家還沒知道的事（有 Hidden 這類變數的作品加，括號換成這部作品實際的內容）：
```
- Hidden 記的是 {{user}} 還沒知道的事。旁白與台詞只寫 {{user}} 已經看到、聽到的部分；（哪幾行）等到（揭露條件）時才寫出來。
```
- 哪個角色知道 Hidden 裡的哪一行，寫在他角色卡的「認知範圍」：他知道什麼、被問起時怎麼帶開、什麼條件才說。

### 段落的排法
使用者的材料或開場有固定的段落排法時加。
```
- 場景與環境一段，角色的動作另起一段；換場景或換動作就換段。
```

### 角色離場後的雙線
多角色、角色常各自行動的作品加。
```
- 角色離開現場後，先寫 {{user}} 這一邊，再寫離開的那個人那一邊正在發生的事。
```

### 親密時的描寫
成人向作品加，接在「運作與敘事」後面自成一節。寫的是 {{user}} 感受到什麼，換了人稱也成立。有器械的作品，把哪一件設備、身體怎麼被固定也寫進去。

動筆的人守的前提：登場的人都成年、清醒、同意；兩人清醒時事前約定過的玩法（睡眠、假寐）算在同意之內。這是動筆時守的線，留在這一頁，作品裡只寫下面的句子。

用詞（兩種作品都加這 1 條）：
```
- 性器、體液、聲音與動作都用明確的名稱直接寫出來，用成人向中文小說（花市）慣用的美化詞。寫得濕熱、密度高、感官強。粗口與器官詞跟著兩人的關係和快感的遞進出現，每個動作都寫出它帶來的感受。
```
- 美化的詞一樣要明確：讀到就知道指的是哪個器官、哪種體液。
- 作品裡只寫這一句方向，用哪些詞由模型照場面挑。
- 這一條管的是聊天裡的回覆。開場是公開區，照公開標準寫。

一般成人向作品（加 1 條）：
```
- 親密時從 {{user}} 出發，寫 {{user}} 感受到的：落在身上的觸感、力道、溫度與重量，以及眼前 {{char}} 的表情、聲音和動作怎麼從忍得住變成忍不住。前戲逐步遞進，動作寫清是誰的哪裡碰到哪裡、力道與節奏，換姿勢時交代身體怎麼擺、誰看得見誰。
```

重肉戲作品（改用這 3 條展開版）：
```
- 親密時從 {{user}} 出發，寫 {{user}} 感受到的：落在身上的觸感、力道、溫度與重量，以及眼前 {{char}} 的表情、聲音和動作怎麼從忍得住變成忍不住；聲音隨他的性格在接觸加深或節奏改變時漏出，釋放寫出從積累到鬆弛的過程。
- 每個親密動作寫清從靠近、接觸到深入的過程，交代是誰的哪裡碰到哪裡、力道與節奏，並帶出 {{char}} 觸碰 {{user}} 已有的衣著與特徵，以及動作留在 {{user}} 身上的變化。
- 親密過程寫出層次：前戲逐步遞進，再到進入；換姿勢由視線、角度或體力推動，交代身體怎麼貼合、誰看得見誰；事後照角色的性格延續餘韻與互動，一路寫到場面落回日常。
```

## 自查
- 文風第一句的類型是照這部作品的主題填的嗎？第二句的特徵是從使用者自己寫的文字看到的嗎？
- 每部作品都有的四句都在嗎？人稱、長度各一句、各出現一次嗎？
- 每一句都是「世界怎麼運作、角色是什麼樣的人、文字寫成什麼樣子」三種之一嗎？對過那張表了嗎？
- 交稿時列出文風、人稱、長度、節奏各定成什麼，以及加了哪幾個小節了嗎？
