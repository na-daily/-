# 作品文風
> 這套工作流的做法，非官方。

文風是每部作品自己的設定，寫在作品設定（`detailMd`）的「運作與敘事」，再用開場示範。使用者的材料裡已經有文風的寫法時，照他的寫法與格式整理；沒有時用下面固定的一塊，先跟使用者確認文風方向再寫正文。

## 文風區塊：固定的一塊
整塊一起加，不挑句子。第一句照作品寫，其餘照用。
```
## 運作與敘事
- 文風方向：這部作品讀起來的感覺，一兩句。寫明基調、快慢，張力放在哪裡，大場面留給什麼。
- 以第二人稱「你」稱呼 {{user}}，每一句都寫出主詞，不省略。
- 這個世界不是圍繞著 {{user}} 運作的，任何角色依然照自己的工作與作息過日子，外面的事透過通知、文件與人的往來進入場景。
- 每則回覆約 800 到 1500 字，篇幅分給現場與 {{char}} 兩邊，現場只寫此刻和人物牽連的細節，最後停在方便 {{user}} 回應的地方。
- 台詞分段：一段只放一到兩句，話多就拆成好幾段，每段另起一行並標上說話的人。
- 從 {{char}} 的視角寫：他看到、聽到、碰到什麼就寫什麼。{{user}} 設定與狀態裡已有的特徵在他注意到時出現；{{user}} 自己照鏡子、低頭看的時候也會出現。
- {{char}} 主動推進劇情：他有自己的判斷，照它和手上正在做的事行動。每個行動是前一件事的結果，也帶來下一件事。
- 角色只依親眼看到、親耳聽到和本來就知道的事行動。
```
- 這幾句講的是所有角色，用不加數字的 `{{char}}`。字數範圍可依作品調整。整段連同下面加的小節以一千字左右為參考。
- 主動推進靠的是因果。「陰謀」「意外」「發生事情」「危機」這些詞不寫進作品，模型會每回合製造事故；也不寫「不要被 {{user}} 牽著走」，寫成他有自己的判斷就夠。
- 不列物件、部位、五感、動作的清單，模型會每一則照著清單寫。不寫「只寫 `{{char}}` 這一側」，模型會連 {{user}} 已有的外貌與衣著都不敢提。
- 句子寫成正文要有的結果，不寫成要模型先推演的步驟（思考過程在 Tikita 會直接印給玩家看）。
- 回覆裡要排固定畫面的作品（平台介面、彈幕、系統視窗），在稱呼那一句後面接著寫畫面版型放在回覆的哪裡，用程式碼區塊排。
- 模型學長度與密度主要看開場，開場本身要寫到對應的密度。
- 整理既有作品時，講同一件事的舊句整句換成這一塊對應的那一句，不兩句並存；作品自己特有的寫法留著。
- 機制什麼時候觸發寫在世界觀或變數說明。敘述規則不寫「用繁體中文」這類語言名稱的句子。

## 看作品才加
**內心話**（要把角色的心聲寫出來，或要明確走外部視角的作品，二選一）
```
- 角色心裡的感受寫在他的視角與引用另起一行的內心話裡，情緒起伏越大，心裡的話可以越多。
```
```
- 旁白只寫從外面看得出來的事：角色心裡的想法只有他自己知道，情緒從他的動作與神情裡讀出來，旁人可能誤解、可能錯過。
```

**角色的主動性與認知**（放在作品設定「各項規則」底下，沒有那一節就放「運作與敘事」）

關係由角色主動往前（戀愛向作品都加；有好感數值或關係階段的作品一定要加）：
```
- 好感高不等於已經在一起。關係要有人開口才會往前：{{char}} 喜歡到藏不住時，會照自己的性格主動做點什麼，找理由見面、送特地挑的東西、把心意說出口；之後提交往、求婚也由他開口。關係只在告白並得到 {{user}} 回應時才改成戀人，發生親密不算確認關係。
```
- 少了這一句，模型常在第一次親密之後直接把兩人當成情侶，角色也只等玩家推。不寫「數值變動不直接轉成告白」這類把角色按住的句子。
- 他會怎麼告白、送哪一類東西，寫在角色卡「與 {{user}}」，照他的性格寫傾向，只給類別。告白、求婚有專屬章節的作品，章節寫「由他開口時」與「{{user}} 先開口時」兩種。

玩家不需要知道的變數（有 Hidden 這類變數的作品加，括號換成這部作品實際的內容）：
```
- Hidden 變數記的是 {{user}} 還不知道的事。旁白與台詞只寫 {{user}} 已經看到、聽到的部分；（哪幾行）等到（揭露條件）時才寫出來。
```
- 哪個角色知道 Hidden 裡的哪一行，寫在他角色卡的「認知範圍」：他知道什麼、被問起時怎麼帶開、什麼條件才說。

**段落的排法**（作品有固定的段落排法時）
```
- 場景與環境一段，角色的動作另起一段；換場景或換動作就換段。
```

**角色離場後的雙線**（多角色、角色常各自行動的作品）
```
- 角色離開現場後，先回應 {{user}} 的行動，再切到離開的那個人，兩邊輪流推進。
```

**親密時的描寫**（成人向作品加，接在「運作與敘事」後面自成一節）

親密時改從 {{user}} 出發，寫 {{user}} 感受到什麼：
- 落在 {{user}} 身上的：觸感、力道、溫度、重量。
- {{user}} 眼前看到、聽到的對方：表情、聲音、動作，寫它們怎麼從忍得住變成忍不住，用前後的差別寫。
- {{user}} 自己的反應、動作與決定留給玩家，不代寫。
- 有器械的作品，把哪一件設備、身體怎麼被固定也寫進去。

一般成人向作品（加 1 條）：
```
- 親密時從 {{user}} 出發，寫 {{user}} 感受到的：落在身上的觸感、力道、溫度與重量，以及眼前 {{char}} 的表情、聲音和動作怎麼從忍得住變成忍不住。前戲逐步遞進，動作寫清是誰的哪裡碰到哪裡、力道與節奏，換姿勢時交代身體怎麼擺、誰看得見誰，不用曖昧詞模糊動作事實。
```

重肉戲作品（改用這 3 條展開版）：
```
- 親密時從 {{user}} 出發，寫 {{user}} 感受到的：落在身上的觸感、力道、溫度與重量，以及眼前 {{char}} 的表情、聲音和動作怎麼從忍得住變成忍不住；聲音隨他的性格在接觸加深或節奏改變時漏出，釋放寫出從積累到鬆弛的過程，不用曖昧詞模糊動作事實。
- 每個親密動作寫清從靠近、接觸到推進的過程，交代是誰的哪裡碰到哪裡、力道與節奏，並帶出 {{char}} 觸碰 {{user}} 已有的衣著與特徵，以及動作留在 {{user}} 身上的變化。
- 親密過程寫出層次：前戲逐步遞進，不直接跳到進入；換姿勢由視線、角度或體力推動，交代身體怎麼貼合、誰看得見誰；事後照角色的性格延續餘韻與互動，讓場面落回日常，不直接跳過。
```

## 開場的寫法：活場接龍
開場是模型照著學的示範，怎麼接都在開場演給它看。要模型之後每一則都照做的事，寫在作品設定的文風區塊。

句子的長短照作品的文風方向。沒有指定時用白描；使用者明說要接龍的質地時，用最後一節「接龍的長句」。

### 動筆前先排順序
先想整場戲的感官順序與走向，再動筆。例如：看天上 → 看到前面 → 看到自己的腳。視線、聲音或觸感沿著一條有前後邏輯的路線移動，排好之後每一句照這條路線接下去，不來回跳。

使用者可以先給一小段，從他那一段的順序與質地往下延伸，他寫的那一段原樣保留。

### 怎麼接
1. **從一個已經在進行的時刻接進去**：時間、地點、站位、情緒的餘波在第一段交代清楚。
2. **句子沿著注意力與行動推進**：先察覺對象，再依目的行動。上一句結尾的東西，成為下一句的起點；換對象、換地點之前，先寫是什麼把注意力帶過去的。
3. **感官照抵達的先後寫**，只寫當下有效的，不湊齊五感。遠近、明暗、有沒有碰到，決定他能知道什麼。
4. **人物、道具、位置、姿勢要有來處**。過程可以簡寫，前後要接得上；環境與道具在有作用時才出現。
5. **作者知道的幕後秘密不寫成角色的心聲**；不替 {{user}} 編沒設定過的特徵。
6. **結尾停在自然的動作、對話或等待上**，允許停頓與沒解決的問題，不硬塞新的人物、事故或轉折。

### 校對
寫完照這幾條改：先砍廢話，再合併囉嗦的句子，再直接寫事實。
1. 動作寫在互動裡，不給身體某個部位孤立的特寫。
2. 留下來的細節要推動關係或劇情，不平均描寫光線、氣味和五官。
3. 通用的身體反應換成只屬於這個角色的反應，沒有必要時不寫。
4. 轉折句型（不是…而是…、並沒有…只是…）只留給真的有誤會的時候。
5. 寫不出具體的就整句刪。要比喻時取材自這個人的特性與生活。
6. 同一篇裡不重複用過的詞語、動作和句式；設定裡的原文不照抄進正文。
7. 破折號少用；正文裡不插入作者的主觀評價，不用括號解釋。

### 接龍的長句（使用者明說要時）
畫面像一條線慢慢展開，句子之間靠同一個意象銜接。適合重視氛圍與細節的作品。先照上面排好順序，再照這幾條寫。
- 視線沿著排好的路線前進，或讓一種聲音、光、氣味從頭貫穿到尾，結尾收在那個感官上，不做總結。
- 上一句的結尾名詞，成為下一句的起點。一個句子容納三四個彼此牽連的意象，用逗號推進。
- 物件帶著時間與因果（放了多久、怎麼變成現在這樣），光、聲音、氣味符合現實。
- 全段不使用情緒詞，氛圍由物件累積。小動作優先，大動作留給劇情需要的時刻。
- 同一個意象出現第二次時，看它有沒有帶來新資訊，沒有就刪。
