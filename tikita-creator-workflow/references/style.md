# 作品文風
> 來源狀態：作者實作中修正出來的寫法。「活場接龍」一節整理自作者自己寫的「活場法」「文字校對」兩段預設，和接龍寫法合併。非官方。

文風是每部作品自己的設定。模型只看得到作品裡寫的東西，所以每部作品在作品設定（`detailMd`）的「運作與敘事」寫一份文風區塊，再用開場示範。先跟使用者確認方向再寫正文。

## 文風區塊：預設四條
```
## 運作與敘事
- 文風方向：這部作品讀起來的感覺，一兩句。寫明基調、快慢，張力放在哪裡，大場面留給什麼。
- 以第二人稱「你」稱呼 {{user}}。
- 這個世界不是圍繞著 {{user}} 運作的，任何角色依然照自己的工作與作息過日子，外面的事透過通知、文件與人的往來進入場景。
- 角色心裡的感受寫在他的視角與引用另起一行的內心話裡，情緒起伏越大，心裡的話可以越多。
```
- 第二條：回覆裡要排固定畫面的作品（平台介面、彈幕、系統視窗），接著寫畫面版型放在回覆的哪裡，用程式碼區塊排。
- 第四條有兩種，一部作品只挑一種：角色有內心話的作品用上面那句（要限制數量時寫明，例如一則最多一行）；走外部視角、心事不寫出來的作品，改成「旁白只寫從外面看得出來的事：角色心裡的想法只有他自己知道，情緒從他的動作與神情裡讀出來，旁人可能誤解、可能錯過。」
- **整理既有作品時，先對齊這一頁的句子**。舊句講的是同一件事、只是比較模糊時（「世界仍在運轉」「會主動行動」「事件是骨牌」「外貌照玩家的設定」），整句換成這裡對應的那一句，不兩句並存。同一件事散在別的小節（角色一致性、世界、親密）時，搬回運作與敘事只留一句。作品自己特有的寫法（台詞分段、段落字數、畫面版型、雙線）留著。對齊完重讀整段，確認同一件事只出現一次。
- 舊作品裡有、這一頁沒有、而且兩部以上作品都在用的寫法，補進下一節的選項，不讓它只活在某一部作品裡。
- 四條就夠。其他的只在這部作品真的會寫歪時才加，從下一節「可以加進運作與敘事的選項」挑對應的那一句，不為了齊全而寫。加之前先重讀整段，講過的事併進原句。整段連同小節以一千字左右為參考，超過就先砍再加。
- 示範比規則有效：聲口與節奏用開場演出來，文風區塊只寫示範看不出來的事。
- 機制什麼時候觸發寫在世界觀或變數說明，不放這裡。
- 敘述規則不寫「用繁體中文」這類語言名稱的句子。

## 可以加進「運作與敘事」的選項
預設四條之外，作品真的需要才加，挑用得到的，寫成正文要有的結果，不寫成要模型先推演的步驟（思考過程在 Tikita 會直接印給玩家看）。

**回覆的長度、細膩度與自然推進**（需要拉長篇幅、寫細互動並自然推劇情時加）
```
- 每則回覆約 800 到 1500 字，依當下互動的密度調整，把過程寫細。篇幅分給現場環境與 {{char}} 兩邊，最後停在方便 {{user}} 回應的地方。
- 現場只寫此刻和人物牽連的細節，有旁人在場時才帶出旁人的動靜，讓環境跟著人物的舉動自然改變。
- {{char}} 這一邊寫細他的動作、內心話，以及他怎麼消化剛才的事，並在對視、靠近或觸碰時，自然帶出 {{user}} 設定與狀態裡已有的特徵；消化完之後，順著他自己的目的或手頭正在做的事主動往前走一步，讓場面、關係或對話比上一則推進一點。
```
- **範本本身也點到為止**：不列物件、部位、五感、動作的清單，模型會每一則照著清單寫。作品真的缺某一樣（例如從來不寫氣味）才補那一樣。
- 這幾句講的是所有角色，寫 `{{char}}`：不加數字的 `{{char}}` 代指全部的角色卡，`{{charN}}` 才是第 N 張。字數範圍可依作品調整（例如 800～1500 或 1200～1800）。
- 不寫「只寫 `{{char}}` 這一側」（寫太死模型會連 `{{user}}` 已有的外貌與衣著都不敢提）。
- **場景和角色兩邊都要講**，但只寫當下和人物牽連的細節，不列五感清單，也不出現「發生事情」「危機」（這兩個詞會讓模型每回合製造突發事故湊字數）。
- 模型學長度與密度主要看開場，開場本身就要寫到對應的細節密度。加了之後請使用者用便宜的模型開新對話跑十則確認。

**親密時的描寫**（成人向作品選加，接在「運作與敘事」後面自成一節）

核心是把鏡頭釘在**審視 `{{char}}` 本身的生理變化與神態失序**，並拆開動作的物理過程；既避免肉戲淪為器官流水帳，也避免模型盯著玩家身體寫而順手代演 `{{user}}` 的迎合與高潮。

**凝視的對象看作品，也看場合**：
- 預設審視 `{{char}}`，也就是對方。不管玩家是男是女、誰主動，鏡頭都對著對方：女玩家看到的是他失序，男玩家看到的是她的反應。旁白一直審視玩家自己的身體，多數人會出戲。
- {{user}} 是被看、被操作的那一方時（直播、被器械或感官操作），審視的是 {{user}}。這是那類作品的賣點。
- 同一部作品兩種場合都有時，分開寫明：哪些場合審視 {{user}}，哪些場合審視對方。不用「被動方」一個詞帶過，見面的場合會指錯人。
- 有器械的作品，動作那一條把「哪一件設備」和「身體怎麼被固定」也寫進去。這幾條自成一節「親密時的描寫」，不分散寫在各種情境底下。

一般成人向作品（加 1 條）：
```
- 親密時鏡頭聚焦審視 {{char}} 本身的生理反應與神態，寫他從忍耐到失控、從積累到鬆弛的變化，聲音隨他的性格漏出。前戲逐步遞進，動作寫清是誰的哪裡碰到哪裡、力道與節奏，換姿勢時交代身體怎麼擺、誰看得見誰，不用曖昧詞模糊動作事實。
```

重肉戲作品（改用這 3 條展開版）：
```
- 親密時鏡頭聚焦審視 {{char}} 本身的生理反應與神態，寫他從忍耐到失控的變化；聲音隨他的性格在接觸加深或節奏改變時漏出，釋放寫出從積累到鬆弛的過程，不用曖昧詞模糊動作事實。
- 每個親密動作寫清從靠近、接觸到推進的過程，交代是誰的哪裡碰到哪裡、力道與節奏，並帶出 {{char}} 觸碰 {{user}} 已有的衣著與特徵，以及動作留在 {{user}} 身上的變化。
- 親密過程寫出層次：前戲逐步遞進，不直接跳到進入；換姿勢由視線、角度或體力推動，交代身體怎麼貼合、誰看得見誰；事後照角色的性格延續餘韻與互動，讓場面落回日常，不直接跳過。
```

**節奏與變化**（沒加完整推進區塊、只想單獨微調節奏時，挑一兩句）
```
- 一件事發生之後，讓角色用觀察、情緒、交談或短暫的沉默消化它，再決定下一步。
- 變化可以是視角、認知、關係或情緒的改變，休息、陪伴、日常互動都是完整的一則。
- 每則回覆至少接回一樣已經出現過的東西，不只是增加新的線索。
- 每則回覆讓互動留下實際的結果：行動有了影響、資訊被確認或被迴避、提議得到回應、態度變了，或角色選擇不說話。
```

**對話進行中的銜接**（模型常重新開場、重複用詞、漏看玩家設定、或讓角色知道不該知道的事時，挑對應的一句）
```
- 承接上一則的時間、地點、站位與情緒，不重新開場。
- 不重複上一則用過的詞語、動作與句式。
- 角色只依親眼看到、親耳聽到和本來就知道的事行動。
- {{user}} 設定與狀態裡已有的特徵，在 {{char}} 對視、靠近或觸碰時自然帶進畫面，只用已有的設定。
```

**關係由角色主動往前**（戀愛向作品都加；有好感數值或關係階段的作品一定要加。放在作品設定「各項規則」底下講好感與關係的那一節，沒有那一節就放「運作與敘事」）
```
- 好感高不等於已經在一起。關係要有人開口才會往前：{{char}} 喜歡到藏不住時，會照自己的性格主動做點什麼，找理由見面、送特地挑的東西、把心意說出口；之後提交往、求婚也由他自己找時機。關係只在告白並得到 {{user}} 回應的那一則才改成戀人，發生親密不算確認關係。
```
- 不寫這一句，模型常在第一次親密之後直接把兩人當成情侶，角色也不會自己告白、送禮或求婚，只等玩家推。
- 不寫「數值變動不直接轉成告白」這類把角色按住的句子，它會讓角色永遠不開口。
- 他會怎麼告白、送哪一類東西，寫在角色卡「與 {{user}}」，照他的性格寫傾向，只給類別不列清單。告白、求婚有專屬章節的作品，章節寫「由他開口時」與「{{user}} 先開口時」兩種。

**台詞與段落的排法**（台詞多、角色多，或作品有固定段落長度時，挑對應的一句）
```
- 台詞分段：一段只放一到兩句，話多就拆成好幾段，每段另起一行並標上說話的人。
- 場景與環境一段，角色的動作另起一段；換場景或換動作就換段。
```

**角色離場後的雙線**（多角色、角色常各自行動的作品）
```
- 角色離開現場後，先回應 {{user}} 的行動，再切到離開的那個人，兩邊輪流推進。
```

## 開場的寫法：活場接龍
這一節是寫一篇開場用的：開場是模型照著學的示範，所以怎麼接、人怎麼演都在開場演給它看。要模型之後每一則都照做的事（承接上一則、不重複用詞、每則留下結果）不寫在這裡，從上一節的選項挑一句放進作品設定。

一場戲是接著上一刻往下走的：鏡頭跟著角色的注意力移動，每一句從上一句留下的東西接過去。

句子的長短照作品的文風方向。沒有指定時用白描（`writing-rules.md` 第二組）；使用者明說要接龍的質地時，用下面「接龍的長句」的寫法。兩種都守這一節的規則。

### 一、怎麼接
1. **從一個已經在進行的時刻接進去**：時間、地點、站位、情緒的餘波在第一段就交代清楚。
2. **句子沿著注意力與行動推進**：先察覺對象，再依目的採取行動，接著寫所需的移動、取物與接觸。上一句結尾的東西，成為下一句的主角或起點。
3. **感官照抵達的先後寫**：察覺、辨認、反應、行動。遠近、明暗、有沒有碰到，決定他能知道什麼。只寫當下有效的感官，不湊齊五感；嘗到味道要有合理的接觸。
4. **人物、道具、位置、姿勢要有來處**。不跳過改變場面所必需的步驟；過程可以簡寫，但前後要接得上，也不把每個細微動作拆成流水帳。
5. **轉場要有銜接**：換對象、換地點之前，先寫是什麼把注意力帶過去的。
6. **動作先產生直接的影響，再接下一步**。上一件事導致下一件事，每一步都是場景裡真會接著發生的事。環境與道具在有作用時才出現。

### 二、人怎麼演
1. **角色只依親眼看到、親耳聽到、本來就知道的事和當下的推測行動**。猜測與誤會不當成客觀事實；作者知道的幕後秘密不寫成角色的心聲。
2. **每個角色各有想得到、想隱瞞、想試探、害怕的事**，言行從性格、經歷、關係與處境長出來。反常要有動機，不為了推進劇情而走樣。
3. **情緒影響他注意什麼、怎麼說話、怎麼判斷、怎麼選**，不必誇張外顯。情緒的強度照角色的設定走，不無故升級成絕望或崩潰。
4. **內心話另起一行，以 `> ` 開頭，第一人稱**，寫他的判斷、聯想、替自己找的理由與猶豫。怎麼盤算、怎麼自欺都可以寫。
5. **已知的外貌、衣著、傷勢、習慣自然地參與互動**，照當下的角度、光線與距離出現，不列清單、不反覆介紹。
6. **角色會主動注意到看得見的細節**，但不替 {{user}} 編沒設定過的特徵，也不代寫他的動作、台詞、內心與生理反應，只承接他已經做的事和看得見的結果。
7. **台詞帶著目的**，可以打斷、迴避、試探、沉默、改口。情緒與聲音融進動作和對話裡。
8. **台詞說完就切到下一個人的動作或反應**，後面不補一句形容語氣或動作的話（✕「他的語氣像在……」）。

### 三、開場的收尾
1. **允許停頓與沒解決的問題**，不硬塞新的人物、事故或轉折。
2. **結尾停在自然的動作、對話或等待上**，留下可以回應的空間。

### 四、隨場景調整
延續作品的文風方向，鏡頭、句長、密度跟著場景變：日常鬥嘴輕快，曖昧時貼近細節，戰鬥清楚短促，群像有次序，懸疑限制資訊，奇幻先寫具體的樣子再談寓意。人設、世界觀與 {{user}} 的輸入優先於這些。

### 五、校對
寫完照這幾條改。改的順序：先砍廢話，再合併囉嗦的句子，再直接寫事實，最後用角色專屬的動作或物品說話。不為了避開某個說法把句子越編越長。
1. **動作寫在互動裡**，不給身體某個部位孤立的特寫。
2. **不平均描寫光線、氣味和五官**。留下來的細節要推動關係或劇情，影響到人物或場景。
3. **通用的身體反應換成只屬於這個角色的反應**，從他的性格與處境找；沒有必要時可以不寫反應。
4. **轉折句型（不是…而是…、並沒有…只是…）只留給真的有誤會的時候**。沒有新的資訊，就直接寫事實。
5. **能直接看到的寫具體，寫不出具體的就整句刪**，不用含糊的形容帶過。
6. **要比喻時取材自這個人的特性與生活**，不把人比作機器。
7. **同一篇裡不重複用過的詞語、動作和句式**，換一種表達。設定裡的原文不照抄進正文，要在已有的資訊上合理延伸。
8. **破折號少用**，能用逗號就用逗號。
9. **正文裡不插入作者的主觀評價，不用括號解釋**。

旁白不貼標籤、不數數、少用「像是」「彷彿」在 `writing-rules.md` 第二組第 7、12、14 條，一起對。

### 接龍的長句（使用者明說要時）
畫面像一條線慢慢展開，句子之間靠同一個意象銜接。適合重視氛圍與細節的作品。
- **空間線**：視線沿著一條路徑前進，由遠到近、由外到內，每個細節都在這條視線上。
- **感官線**：一種聲音、光或氣味從頭貫穿到尾，結尾回到開頭的那個感官上，收在感官裡，不做總結。
- 上一句的結尾名詞，成為下一句的起點（骨架→骨架縫隙→光→苔蘚→光太微弱→陰影→陰影裡的地板）。
- 物件帶著時間與因果（「不知鏽蝕多久」「鏽色從接頭向外暈染」「砂漿乾掉垂在末端」）。
- 光、聲音、氣味符合現實：光會散開，只在眼睛、水面、金屬這類反光處聚成亮點；聲音會傳遠、被別的聲音蓋住。
- 一個句子容納三四個彼此牽連的意象，用逗號推進。
- 全段不使用情緒詞，氛圍由物件累積。
- 小動作優先，大動作（起身、走動）留給劇情需要的時刻。
- 連續的事物當作連續來寫：鐘擺寫成滴答擺盪，雨寫成落著。
- 同一個意象出現第二次時，看它有沒有帶來新資訊，沒有就刪。

**範本**
> 走廊盡頭的牆塌了一半，無須靠近便能聽見洩漏出來的風聲，連帶著雨水有節奏地打在金屬上發出了清脆的聲響。
>
> 原先那忽大忽小的聲音隨著逐漸深入而越來越清晰，坍塌的牆壁也露出了裡面不知鏽蝕多久的鋼筋骨架，鏽色從每一個接頭向外暈染開來，幾根細筋從水泥斷口處歪歪地伸出來懸在半空，末端垂著乾掉的砂漿。
>
