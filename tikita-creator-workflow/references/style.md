# 敘事指示：作品設定的「運作與敘事」
> 這套工作流的做法，非官方。

敘事指示是寫在作品設定「運作與敘事」一節、要模型每一則回覆照著寫的句子。Tikita 沒有讓玩家選人稱、長度或文風的地方，這些全部由作品自己寫定，所以動筆前先確認作品的題材、{{user}} 和角色的關係、玩家主要在做什麼、是不是成人向，再照這部作品寫。

## 寫法
- 每一句寫世界怎麼運作、角色是什麼樣的人，或正文寫成什麼樣子，因為模型會照字面演出來，它的思考過程在 Tikita 也會直接印給玩家看。
- 下面每一項都附了參考句，照作品改寫或換掉，用不到的整項省略。整段以一千字內為參考。
- 會發生的事件寫在世界觀或章節，由那裡的條件帶出來；回覆收在哪裡交給開場示範。
- 交稿時用一兩句告訴使用者每一項定成什麼。

這幾種說法會被模型照字面演歪，寫完對一次：
| 寫了 | 模型會演成 |
|---|---|
| 停在方便 {{user}} 回應的地方、留鉤子 | 結尾出現「等著你的回應」 |
| 主動推進劇情 | 角色每一則硬找事做 |
| 張力、衝突、意外、危機 | 每回合出事 |
| 只寫 {{char}} 這一側 | 連 {{user}} 的外貌與衣著都略過 |

## 要寫的幾項
**1. 世界與角色怎麼動**，每部作品都寫。用沒有數字的 `{{char}}`，指的是所有角色。
```
- 世界照自己的步調運作，每個角色都有自己的工作、作息與想做的事。
- {{char}} 依自己看到、聽到與本來就知道的事判斷和行動，每個舉動都接在前一件事之後，場面平靜時就照日常的步調過。
```

**2. 視角**，預設第二人稱；群像或 {{user}} 常離場的作品用第三人稱；只有一個主要角色、看點在他怎麼想的作品，可以用他的第一人稱。
```
- 以第二人稱「你」稱呼 {{user}}。
```

**3. 長度與節奏**，預設順著玩家的方向擴寫。傳訊息、直播聊天室這類一來一往很快的作品改成「每則回覆寫一個動作或一段對話」；經營、任務這類一則要過很多事的作品改成「一則回覆可以跨過一段時間，瑣碎的過程一句帶過」。使用者明說要字數時才寫字數。
```
- 每則回覆順著 {{user}} 這一則的方向細膩地擴寫，寫的是當下這一小段時間。
```

**4. 文體**，括號填最接近這部作品主題的小說或故事類型。使用者給過自己寫的段落時，再加一句從那段文字看得到的特徵（句子長短、對話多寡、口語或書面）。
```
- 以（類型）的筆法、敘事散文的寫法書寫，句子之間用因果、轉折與先後接起來，場景隨人物的移動和視線展開，帶出季節、光線、溫度與動作的過渡。
- 每一句寫出主詞。台詞一段一到兩句，話多就分段，每段另起一行並標上說話的人。
```

**5. 內心**，照作品選一種：看點在角色心裡的作品（偏執、陰濕、表裡不一）用第一句；使用者本來就用獨立內心話的格式時用第二句；懸疑、要玩家自己猜的作品用第三句。
```
- 角色的情緒有明顯起伏時，旁白直接寫出他因為什麼而有了什麼感受。
- 角色的心聲另起一行，以「> 」開頭，用第一人稱寫。
- 旁白只寫外面看得出來的事，角色的心思從他的動作與神情裡讀出來。
```

**6. 關係與認知**，戀愛向或有好感、關係階段的作品寫第一句，讓第一次親密之後關係還是照原樣，角色也會自己表示；有 Hidden 這類玩家不需要知道的變數時寫第二句，括號換成實際的內容。這一項放在作品設定的「各項規則」，沒有那一節時放這裡。
```
- {{char}} 喜歡上 {{user}} 時，會照自己的性格讓對方知道，交往、結婚也是他自己會提的事；兩人在告白並得到回應時才成為戀人，在那之前的親密不改變原本的關係。
- Hidden 記的是 {{user}} 還沒知道的事，旁白與台詞只寫 {{user}} 已經看到、聽到的部分，（哪幾行）在（條件）時才寫出來。
```

**7. 其他**，用得到才加：開場有固定的段落排法（環境一段、動作另起一段）、多角色常各自行動時寫離開的那一邊正在發生什麼、回覆裡要排平台介面或彈幕時寫版型放在哪裡並用程式碼區塊排。

## 親密時的描寫（成人向）
接在「運作與敘事」後面自成一節。動筆的人守的前提是登場的人都成年、清醒、同意，兩人清醒時事前約定過的玩法（睡眠、假寐）算在同意之內；這條線留在這一頁，作品裡只寫描寫的方式。這一節管的是聊天裡的回覆，開場照公開區的標準寫。

一般作品寫前兩句，重肉戲的作品三句都寫；有器械的作品把是哪一件設備、身體怎麼被固定也寫進去。
```
- 親密時用花市慣用的美化詞直接寫出性器、體液、聲音與動作，讀到就知道指的是哪裡，寫得濕熱、綿密、感官強烈，粗口與器官詞隨兩人的關係和快感的遞進出現。
- 親密從 {{user}} 的感受寫起：落在身上的觸感、力道、溫度與重量，以及 {{char}} 的表情、聲音和動作怎麼從忍得住變成忍不住；每個動作寫清是誰的哪裡碰到哪裡、力道與節奏，前戲逐步遞進，換姿勢時交代身體怎麼貼合、誰看得見誰。
- 聲音隨他的性格在接觸加深時漏出來，釋放寫出從積累到鬆弛的過程，動作留在 {{user}} 身上的痕跡也寫出來；事後照他的性格延續餘韻，一路寫到場面落回日常。
```
