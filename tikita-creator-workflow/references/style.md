# 敘事指示：作品設定的「運作與敘事」
> 這套工作流的做法，非官方。

敘事指示是寫在作品設定「運作與敘事」一節、要模型每一則回覆照著寫的句子。Tikita 沒有讓玩家選基調、人稱或長度的地方，這些全部由作品自己寫定，所以動筆前先確認作品的題材與基調、{{user}} 和角色的關係、是不是成人向，再照這部作品寫。

## 寫法
- 每一句都寫成模型讀得懂、做得到的具體說法：世界照什麼常理運作、角色能知道和做到什麼、正文寫成什麼樣子。模型會照字面演出來，它的思考過程在 Tikita 也會直接印給玩家看。
- 下面每一項附了參考句，照作品改寫或換掉，用不到的整項省略。整段以一千字內為參考。
- 事件寫在世界觀或章節，由那裡的條件帶出來；回覆收在哪裡交給開場示範。
- 交稿時用一兩句告訴使用者每一項定成什麼。

這幾種說法會被模型照字面演歪，寫完對一次：
| 寫了 | 模型會演成 |
|---|---|
| 停在方便 {{user}} 回應的地方、留鉤子 | 結尾出現「等著你的回應」 |
| 主動推進劇情、世界照自己的步調運作 | 每一則硬塞事件或別人的動靜 |
| 張力、衝突、意外、危機 | 每回合出事 |
| 以某某筆法、有氛圍、細膩 | 每個模型的解讀都不一樣 |
| 只寫 {{char}} 這一側 | 連 {{user}} 的外貌與衣著都略過 |

## 要寫的幾項
**1. 故事的基調**，寫這個故事是什麼方向，再接上這個基調在文字上是什麼樣子，模型才照得出來。
```
- 這是一個壓抑、背德的故事：角色的慾望多半藏在克制的動作和沒說完的話裡，場面安靜，情緒往下壓。
- 這是一個陽光、輕鬆的故事：對話多、節奏快，角色之間常互相吐槽，挫折很快就過去。
```
使用者想參照某位作家的筆法時，名字後面一定接上具體的特徵，例如「參考某某的筆法：句子短、對白少、情緒靠動作帶出來」，因為模型不一定熟那位作家，熟的話也容易只學到表面的習慣。

**2. 世界與角色的常識**，每部作品都寫。模型預設會讓世界順著 {{user}}、讓角色無所不能，所以要寫明這個世界照常理運作。
```
- 這個世界照常理運作，不偏向任何人：{{user}} 和 {{char}} 做的事可能成功，也可能失敗，旁人照自己的立場和心情對待 {{user}}，也可能不理會。
- {{char}} 只知道自己親眼看到、親耳聽到和本來就知道的事，只做得到他的身分、能力和手上的資源做得到的事。
- {{user}} 的事由 {{user}} 自己決定、自己去做，{{char}} 只在自己的能力和立場之內出手。
```

**3. 回應的範圍**，每部作品都寫。
```
- 每則回覆接著上一則的最後寫下去，寫 {{char}} 和在場的人對 {{user}} 這一則的反應。
```

**4. 視角**，預設第二人稱；群像或 {{user}} 常離場的作品用第三人稱；只有一個主要角色、看點在他怎麼想的作品，可以用他的第一人稱。
```
- 以第二人稱「你」稱呼 {{user}}。
```

**5. 長度與描寫的重點**，寫具體要寫什麼，不寫字數。傳訊息、直播聊天室這類一來一往很快的作品改成「每則回覆寫一個動作或一段對話」；經營、任務這類一則要過很多事的作品改成「一則回覆可以跨過一段時間，瑣碎的過程一句帶過」。使用者明說要字數時才寫字數。
```
- 每則回覆順著 {{user}} 這一則的方向細膩地擴寫：當下的場景（季節、光線、溫度）、人物的動作與表情，以及動作之間怎麼銜接。
- 用字口語直白，句子用連接詞接成完整的句子，比喻只在必要時用。
- 每一句寫出主詞。台詞一段一到兩句，話多就分段，每段另起一行並標上說話的人。
```
使用者給過自己寫的段落時，用字那一句改成從那段文字看得到的特徵（句子長短、對話多寡、口語或書面）。

**6. 內心**，照作品選一種：看點在角色心裡的作品（偏執、陰濕、表裡不一）用第一句；使用者本來就用獨立內心話的格式時用第二句；懸疑、要玩家自己猜的作品用第三句。
```
- 角色的情緒有明顯起伏時，旁白直接寫出他因為什麼而有了什麼感受。
- 角色的心聲另起一行，以「> 」開頭，用第一人稱寫。
- 旁白只寫外面看得出來的事，角色在台詞裡藏起來的事，旁白也不揭露。
```

**7. 關係與認知**，戀愛向或有好感、關係階段的作品寫第一句，讓第一次親密之後關係還是照原樣，角色也會自己表示；有 Hidden 這類玩家不需要知道的變數時寫第二句，括號換成實際的內容。這一項放在作品設定的「各項規則」，沒有那一節時放這裡。
```
- {{char}} 喜歡上 {{user}} 時，會照自己的性格讓對方知道，交往、結婚也是他自己會提的事；兩人在告白並得到回應時才成為戀人，在那之前的親密不改變原本的關係。
- Hidden 記的是 {{user}} 還沒知道的事，旁白與台詞只寫 {{user}} 已經看到、聽到的部分，（哪幾行）在（條件）時才寫出來。
```

回覆裡要排平台介面或彈幕的作品，另外加一句寫版型放在哪裡，用程式碼區塊排。

## 親密時的描寫（成人向）
接在「運作與敘事」後面自成一節。動筆的人守的前提是登場的人都成年、清醒、同意，兩人清醒時事前約定過的玩法（睡眠、假寐）算在同意之內；這條線留在這一頁，作品裡只寫描寫的方式。這一節管的是聊天裡的回覆，開場照公開區的標準寫。

「每次都寫出名稱」是為了讓模型不用「那裡」「那處」這類代稱。一般作品寫前兩句，重肉戲的作品三句都寫；有器械的作品把是哪一件設備、身體怎麼被固定也寫進去。
```
- 親密時直接寫出性器、體液、聲音與動作，每次提到身體的部位都寫出它的名稱，用詞美化而不粗俗；寫得濕熱、綿密、感官強烈。
- 親密從 {{user}} 的感受寫起：落在身上的觸感、力道、溫度與重量，以及 {{char}} 的表情、聲音和動作怎麼從忍得住變成忍不住；每個動作寫清是誰的哪裡碰到哪裡、力道與節奏，前戲逐步遞進，換姿勢時交代身體怎麼貼合、誰看得見誰。
- 聲音隨他的性格在接觸加深時漏出來，釋放寫出從積累到鬆弛的過程，動作留在 {{user}} 身上的痕跡也寫出來；事後照他的性格延續餘韻，一路寫到場面落回日常。
```
