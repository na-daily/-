# 敘事指示：作品設定的「運作與敘事」
> 這套工作流的做法，非官方。

每部作品都從這一塊開始，括號照作品填。

```
## 運作與敘事
- 這是一個（基調）的故事：（這個基調在文字上的樣子）。
- 所有角色的行動成敗取決於自身的交涉技巧、經濟能力與社會地位。
- 用（第三／第二）人稱敘事，禁止省略主詞。
- 旁白跟著在場的 {{char}}，寫他當下看到、聽到、碰到的事和心裡的感受；{{char}} 不在場時，改跟著 {{user}}，只寫 {{user}} 感官接收到的事。
- 台詞說長了就分段，每段另起一行並標上說話的人。
```

基調的例子：「壓抑、背德：角色的慾望藏在克制的動作和沒說完的話裡，場面安靜，情緒往下壓」「陽光、輕鬆：對話多、節奏快，角色之間常互相吐槽」。人稱由使用者決定。成敗的三個條件照作品換（武力、異能、人緣、成績）。長度、節奏與文筆交給開場示範。

## 照作品改或加
| 作品 | 改或加 |
|---|---|
| 用獨立的內心話 | 加「{{char}} 心裡想說卻沒說出口的話另起一行，以「> 」開頭，用第一人稱寫。」 |
| 懸疑、讓玩家自己猜 | 旁白那句拿掉「和心裡的感受」，加「角色在台詞裡藏起來的事，旁白也不揭露。」 |
| 常出現手機訊息、文件、螢幕，或有平台介面、彈幕、系統視窗 | 加「角色看到的手機訊息、紙條、告示與螢幕上的文字，原文用程式碼區塊包住。」固定的畫面再加一句寫它什麼時候出現、放在哪裡，接著用程式碼區塊排出版型，會變的地方寫欄位名。 |

## 親密時的描寫（成人向）
接在「運作與敘事」後面。登場的人都成年、清醒、同意，事前約定過的玩法（睡眠、假寐）算在同意之內；這條線動筆的人守，不寫進作品。

```
## 親密時的描寫
- 親密時直接寫出性器、體液、聲音與動作，每次提到身體的部位都寫出它的名稱，用詞美化而不粗俗；寫得濕熱、綿密、感官強烈。
```
