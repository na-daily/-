# 動筆前必讀

寫任何會存進草稿的文字之前讀這一頁，寫完照最後的自查逐條對。這裡每一條都是實際寫作時反覆修正出來的，和其他檔案的說法有出入時以這一頁為準。

使用者有新的糾正時，直接加進這一頁對應的那一組，寫成通用的做法，不寫作品名、角色名、作品裡的道具與台詞。作品裡用不到、不必寫的東西，這份 skill 也不提：不留「某某不用寫」這種句子，提到了反而會被寫進作品。

**規則是為了演出**。照做會讓角色的特性寫不出來時，以角色為準，回報時說明哪一條沒照做、為什麼。這四條沒有例外：設定裡不寫身體表現、不寫模型一則回覆做不到的空話、常駐設定不列清單、好感區間不寫成關係。使用者的原稿和這四條衝突時，先問他要怎麼處理，再整理。

## 一、每一種文字都適用
1. **讀者是負責扮演的模型**。每一句都在指揮它怎麼演。這句拿掉，演出不會變，就刪。
   - **不寫模型一則回覆執行不了的空話**：「順著劇情自然發展」「視情況決定」「隨著相處慢慢…」「在適當時機」「遲早會曝光」。模型只看得到現在這一則，沒有跨回合的排程。不打算綁條件的事整句不寫；要鎖時機的事綁在變數、章節切換條件，或當下看得到的具體動作上。
2. **只寫有的事，用正面的說法**。不用否定式強調（「並不…」「沒有…也沒有」），不描寫缺席（「手邊沒有某樣東西」「還沒開口」）。規則寫成「要做什麼」。
   - **角色自己的事實直接用否定句寫**：他的底線、不做的事、不知道的事、避開的話題。要避開的是修辭上的否定強調，和「不要把他寫成 X」這種指揮模型的禁令。
3. **每件事全作品只寫一處**。加規則前先查它已經寫在哪。同一個反應、同一個說法（「怕弄壞」「又氣又慌」）在角色卡、變數說明、範例對話之間只出現一次，別處換一個角度寫。每次往草稿加東西之後，整份查一次重複句。
   - **往作品設定加句子之前，先重讀那一整節**。已經講過的事併進原句，不另起一句。「運作與敘事」連同底下的小節以一千字左右為參考，超過就先砍再加；一輪一輪往上疊，同一件事很快就會講兩三次。
4. **設定寫長期成立的事**。作品設定、角色卡不寫「上個月」「剛」「最近」「一開局」。只在一開始成立的事不放作品設定：寫進綁定的開局章節的私設；沒有綁章節時，情境交給開場，數值交給變數預設值。✕「爺爺上個月過世」→ ○「爺爺已經過世」。
5. **不加保險句**。平台禁止的題材，設定裡沒有主動寫就好。✕「不能強迫」「親密不拿來抵債」「不替 {{user}} 說話或做決定」「角色皆已成年」「雙方合意」。這類防範句整句不寫，換成正面的說法也一樣不寫。看到舊的就提出刪除。
6. **不寫死會被反覆用的東西**。具體的口頭禪原句、某道菜、某個小動作寫進設定，模型會每則都用。角色卡寫成行為描述。範例對話預設不放：裡面出現的行為、食物、飲料會被模型一直拿來用，聲口與格式靠開場示範，使用者明說要才寫。
   - **常駐設定點到為止**。作品設定、角色卡、變數說明每一則都會送進模型，所以只寫方向與感受，不列動作清單、身體部位清單、五感清單、細節清單；清單裡的每一樣，模型都會每一則照用。真的是查表用的資料（價目、樓層、抽選表）才列。
   - **態度分級也點到為止**。好感高低、身分不同的人怎麼對待 {{user}}，只寫每一級的人怎麼看 {{user}}，做什麼讓模型演。✕「刁難、起鬨、試上限、嘲笑失誤、下指令」→ ○「把 {{user}} 當成笑料，只想看反應」。
7. **設定直白敘述，寫確定的事實**。直接講發生過什麼、他是什麼樣的人、規則怎麼運作。不用抽象的詞代替內容（✕「背負著沉重的過去」），不留鉤子與懸念（✕「似乎藏著…」「那一晚改變了一切」），模型讀到只會自己編。要鎖住的放章節私設，其餘整句不寫。
8. **用字照作品的語言**。繁體中文作品用正字，不混簡體轉來的寫法：嚮導（不寫向導）、哨嚮。
9. **介紹頁不把設定和開場複製貼上**。它是給玩家看的，每一句都為介紹頁重新寫：講玩家的處境，不講規格；角色只給看得到的樣子。鉤子只留在整頁的結尾。
10. **使用者給的修法只用在他指的那一處**。別的地方找符合那個場景的寫法，不照抄。使用者說「抽象」「列資料」時，先弄清楚缺的是畫面還是心境，拿不準就問是哪幾處。

## 二、正文：開場與章節裡的場景
1. **白描**。先寫主詞，再寫他做的事或樣子，一句把一件事講完。不用排比、倒裝、借代來製造氣氛。✕「先從燈下走出來的是一副把走廊佔去大半的肩背」→ ○「走過來的男人很高，肩膀寬得佔去了大半條走廊。」
2. **一段只跟著一個人或一個物件**。寫完這個再換下一段，不在同一段從窗外跳到桌上再跳到手上。換對象之前，先寫是什麼把注意力帶過去的（一個聲音、一個動作）。
3. **句子完整，不碎**。一句容納彼此牽連的幾個動作，用逗號推進；不要三五個字就一個句號，也不要第一句長、後面退回短句。
4. **開場從 {{user}} 所在的位置寫起**，照他會感知到的順序排：他在做什麼，聽見什麼，看見什麼變化，最後才是來的人。不用鏡頭先拍場景、再拍角色、最後才讓玩家進場。
5. **開場與正文一律用「你」稱呼玩家**，不寫 {{user}}。{{user}} 用在設定（作品設定、角色卡、章節、變數、設定集）和介紹頁。使用者的草稿裡寫「{{user}}」當主詞時，存進開場前換成「你」。
6. **旁白不替玩家做動作，台詞不替玩家編過去**。✕「你推開門」「上次你把東西掉了一路」。玩家只出現在角色對他做的事、落在他身上的感覺裡。例外：開場可以交代一個平凡的起始動作當落腳點（剛吃完飯在走廊散步），之後的反應留給玩家。範例對話不放 `{{user}}:` 台詞行。
7. **角色的感受直白地寫進旁白**，寫成他對眼前這件事的反應：發生了什麼，他因此感到什麼。○「知道是自己誤會了你以後，他感到有些羞愧。」不用抽象的說法或比喻替動作貼標籤（✕「那是想拒絕又捨不得的軟」「努力讓語氣聽起來跟平常一樣」），也不順著把他還沒說出口的內情寫出來。
8. **作品有內心話時，內心話另起一行**，以 `> ` 開頭，第一人稱，可以誇張、多用驚嘆號與刪節號；放在對應的旁白之後、台詞之前。旁白維持白描，內心話才負責情緒。
9. **身體反應寫成動作**（倒吸一口氣、手上的力道收緊、別開視線），不寫儀表式的句子（「呼吸變急」「心跳加速」「喉結滑動」「指節泛白」）。情緒可以用一個帶誇飾的具體動作表現，例如盯著包裝背面的標示，盯到快把它看穿。
10. **台詞多就分段，不縮句**。一段一到兩句，每段另起一行、照樣標名字；內心話也分行。不刪內容。
11. **停頓時讓新的東西進場**（一個聲音、環境的變化），不讓角色多做一個小動作來填空。
12. **不數數**。不寫「敲了三聲」「看了兩眼」，連續的事寫成連續。
13. **台詞講完就停**，不再補一句撇清或反轉的短句。
14. **少用「像是…」「彷彿…」**，不用情緒詞替場面定性。資訊讓角色順口帶出，不當成自我介紹。
15. **口語照作品的地區**。台灣的作品用台灣口語（欸、啦、吧）。結巴與停頓只用在需要的角色。
16. **開場結尾平鋪直敘**：直接說現場有什麼等著玩家處理，不堆意象當鉤子，不用「你要怎麼做？」收尾。
17. **不把物件一件件擺位置**（拿起、換手、放下），情境交代一句帶完。

## 三、角色卡
1. **描述人的每一條都從心境寫起**：情境 → 他心裡的感覺、想要的、怕的 → 他因此傾向怎麼做。心境是主體。只列行為會演得像照表操課。
   - **寫到感受與傾向為止，不寫身體表現**。感受（感到羞澀）和傾向（會想躲、會嘴硬）寫進設定；表現（耳根紅、別開視線）留給模型當場演，寫進設定它會每則都用。變數的範圍說明、章節私設、設定集寫到角色反應時也一樣。
2. **口語、連貫的句子**，像在跟人介紹這個角色。不拆成名詞短語，不用「觸發：／能量：／說法：」這種冒號欄位。
3. **講心境的節，第一條以「總結而言：{{charN}} ……」開頭**（現況、附屬存在、狀態、時間線、與 {{user}}、慾望），講他在這一塊整體是什麼樣子。說話風格、與其他人、認知範圍、習慣、資料直接寫。去標籤靠這一句的正面說法，不寫「不要把他寫成 X」，禁令裡的詞會把模型往那邊帶；真的測出演歪才針對那個毛病補一句。
4. **性格從經歷長出來**：經歷 → 留下的心境 → 現在的傾向，按時間排。不貼形容詞標籤。沒有經歷來源的喜好直接列在習慣。
5. **矛盾的感受並列寫出來**（又氣又慌、想靠近又怕弄壞）。說不出口的感受照樣寫進卡，並在說話風格寫明這些留在心裡、嘴上只講什麼。
   - **說話風格寫語氣背後的原因、對誰會變、他自己的用詞類型**。✕「語氣平淡、用詞精確」：只有形容詞，換個名字貼到別的角色身上也通，等於沒寫。
6. **公開卡的範圍只有六樣**：基本資訊、職業、身形、穿著、首先能感受到的性格、與 {{user}} 初遇時的關係。經歷、習慣、更深的性格、對 {{user}} 的態度與反應和原因都放 `secret`。
7. **前後反差與秘密揭露跟著變數或章節走，沒有模糊時機**：
   - 前後反差的另一面預設放角色卡，在「與 {{user}}」底下分小節，小節名稱直接對齊變數的關係階段名（如「還沒認定」「認定之後」）；真的要鎖定、條件達成前不能漏的那一塊才放章節。兩種可以並用。
   - **秘密與可揭開的經歷**：要鎖住的放章節私設，或綁在變數狀態上。角色卡只寫平常的反應，認知範圍寫他不主動提、被問起時怎麼帶開，或拿出哪個具體證據時才不再否認，寫到這裡就停。
   - **要等角色自己說出口才存在的東西（真名、身分），常駐的地方連內容都不寫**。角色卡與變數說明只寫「現在用的是代號、真正的那個只有誰知道」，內容本身只放在揭露的那一章和它之後的章節。寫進卡裡再叮囑「不要提前說」沒有用，模型看得到就會漏。
8. **精神體、寵物、使魔集中寫一節**：外觀、性格、對 {{user}} 和對別人的樣子、平常待的位置、主人對牠的態度。其他段落不再各補一句牠在做什麼。寫牠的傾向（會去討親近、會替主人守著），不列一串固定的動作。
9. **角色的狀態不列觸發原因**。失控、崩潰、發作這類，在私設獨立寫一節「狀態」，每個狀態寫它是什麼、他當時的心境與傾向。何時發作不寫。
10. **資料欄維持條列**（身高、衣物、住所）。成人向的性器設定寫尺寸數值、形狀、顏色三樣。
11. **角色想要的事要寫出原因**：對 {{user}} 一見鍾情、某段經歷，或別的具體原因。這件事對他多重要、被拒絕時怎麼反應，照他的性格、經歷和他怎麼看待 {{user}} 寫，不預設。

## 四、世界觀、地點、劇情
1. **世界觀寫成連貫的段落**，句子之間用因此、所以、不過、至於接起來。先一句講這是什麼樣的世界，再寫同一件事在不同人眼裡的樣子，每個設定後面接它在日常裡造成的結果。真的是清單的東西才條列（任務類型、抽選表、地點、角色出沒）。
2. **先寫根本的**：世界怎麼來的、時代、核心機制、普通人怎麼看。作息、流程、只有名字的地點這類模型自己會演的，一句帶過或不寫。
3. **世界觀要有這部作品自己的特色**，從已經寫好的設定往下推出社會上的規矩與後果，不另開規則或變數。
4. **地點是地圖，最主要寫佈局**：分成哪幾區、各在哪個方位、裡面有什麼、彼此怎麼連通、從哪裡進出。建築物內部照樓層寫（一樓有什麼、二樓有什麼），一層一行。佈局之後再補擺設、光線聲音氣味溫度、常出現的人和他們在做什麼。不列「有商場、電影院、夜市」這種清單，也不寫主要角色在那裡的反應（那屬於角色卡）。
5. **劇情不綁死**。只寫各方平常的態度，以及得知某件事之後會怎麼反應。不排「第一步、第二步」的主線，不寫「什麼事件把劇情推到下一階段」，不為了追主線進度開變數。配角的心結與和解不排成一章，條件寫在他的卡裡。
   - **不預設 {{user}} 的結局**。作品設定、角色卡、章節不寫 {{user}} 最後會怎樣、兩人最後會變成什麼、故事往哪裡收。走到哪裡由玩家的行動決定。
   - 單一主要角色的作品，他的出沒寫在角色卡；{{user}} 沒有特別的身分時在開場交代就好，不在作品設定另開一節；旁人對 {{user}} 沒有特別的立場時不寫「各方的態度」。
6. **開局年份**：近未來或未來題材放未來的年份，不用今天的日期。
7. **作品設定的順序固定**：世界 → 各項規則 → 變數 → 運作與敘事 → 親密時的描寫（成人向才有）。世界是主，怎麼描寫是輔。

## 五、寫給模型的規則
1. **規則以一則回覆做得到的為準，越少越好**。模型一則回覆能做的只有這四種：
   - 這一則發生了某件看得到的事（播種、收成、交付、結帳），把某個值加上或減掉一個寫死的數。
   - 把一個詞換成另一個詞（「已繳」改成「逾期」）。
   - 記「剩幾天」：日期每換一天，把剩下的天數減 1，到 0 時發生該發生的事。
   - 拿現在的值去對一張寫好的表，照表寫結果（累計到 10 是 2 級、到 25 是 3 級；月收入 5000 以下扣 500）。

   要算的地方，動筆的人先算好，把結果列成表。✕ 乘除與比例（「抽成 20%」「只給一半」）、滿了歸零再進位（「滿 100% 升一級並歸零」）、要回頭數已經過了多久（「七天沒來」「每七天加一週」）、取餘數。細節大致吻合就好。
2. **條件是看得見的事**：某個事件發生時、某個變數到達哪一階或哪個數字時、或切進哪個章節時。不寫「適時」「越來越可能」「隨著時間推移」「順著劇情發展」。清單要說挑幾個。
3. **一句一個動作，主詞寫出來**。同一個東西在所有欄位只有一個名字。規則放在它生效的那個欄位，最重要的放最前面。
4. **例子會被照抄**。名字、暱稱這類欄位不放例子；要它輸出的格式直接排出版型給它看。
5. **好感區間寫成心境，不寫成關係**。✕「80 以上戀人」→ ○「80 以上是愛上了」。區間寫成關係，數字一到模型就自動確認。戀人這類關係只在告白並得到 {{user}} 回應時才寫上，不看好感、也不看有沒有發生親密；作品設定配上「關係由角色主動往前」那一句。

## 六、自查
寫完逐條對，命中就回去改，改完再交給使用者。
1. 有沒有「你」或 {{user}} 當主詞、替玩家做了動作或決定的句子？
2. 有沒有修辭上的否定強調、缺席描寫、「像是」「彷彿」？（角色自己不做的事、不知道的事用否定句寫，不算）
