# 世界觀、作品設定、設定集、秘密
> 設定集的運作與上限是官方規則，其餘是這套工作流的做法。

# 世界觀怎麼寫
世界觀是寫給模型的運作規則，不是設定資料集。只寫會改變演出的東西。
「同一件事在不同人眼裡的樣子」可以這樣起頭：對一般人來說…；對某些人而言…；對有權勢的人來說…。另外：
- **只寫模型不知道的**。現實常識與類型慣例（一般的奇幻、校園、ABO 或哨嚮的基本概念）不用重寫，只寫這部作品不一樣的地方。
- **演不到的不寫**。歷史年表、地理百科、與玩家無關的遠方勢力不佔字數；想留就放設定集。
- **規則寫成可以執行的句子**：誰、在什麼情況、會怎樣。✕「這個世界魔法很稀有」→ ○「會魔法的人要登記，沒登記被發現會被帶走；一般人一輩子沒親眼看過魔法」。
- **日常比奇觀重要**：人們怎麼生活、靠什麼過活、有哪些固定活動，模型才有東西可以演過渡與閒聊。
- **世界觀層級的特殊機制只放一個**（超自然的能力、體質、連結這類），寫明運作、限制、例外，以及當事人不在場時怎麼處理。多個機制模型記不住。契約、評級、經濟這類制度不算在內，照下面的骨架一項一節。

# 作品設定 `detailMd` 的骨架
依作品增減，每段只寫整場遊戲都成立的內容。**順序固定：世界是主，內容怎麼描寫是輔，所以世界在前、寫法在後**：
1. **世界**：照上一節寫成段落，後面接條列的清單（陣營對照、空間、日程；多角色時加角色出沒）。
2. **各項規則**：這個世界的機制與制度，一項一節（契約、評級、經濟、路線、指令）。解謎、隱瞞為核心的作品，「什麼算確實知道、誰能知道什麼」也放這裡。
3. **變數**：更新總則一句，加上這部作品特有的更新例外。
4. **運作與敘事**：文風區塊（固定的一塊）。
5. **親密時的描寫**（成人向才有）：親密場面怎麼寫，接在運作與敘事後面。

整理既有作品的順序時只搬位置、不順手改內容，搬完核對字數有沒有變。「運作與敘事」裡的舊句另外對齊文風區塊的句子。

- **開局不寫在作品設定**。作品設定每一則都會送進模型，開局留在這裡會一直佔著提示詞，玩久了還會跟現況打架。
- {{user}} 和角色有關的部分（例如只有 {{user}} 能安撫他）寫在角色卡。
- **會反覆使用的流程，沒有其他章節可以切回去時，直接寫在作品設定**（例如只有「出任務」一套流程的作品）。之後作品有了別的章節，再把它搬成章節。
- 作品設定計入 30,000 字，全部寫在這裡會擠掉角色與開場的額度。

## 世界結構的清單（需要才寫）
- **陣營對照表**：兩個以上的陣營，用表格比較居民、行事風格、玩家的體驗。反差越清楚，模型越不會把兩邊演成一樣。
- **空間**：樓層或區域各自的功能，列在一處。
- **角色出沒表**（多角色的作品才列）：每個角色平常在哪、什麼時候去哪。
- **日程**：固定的週期事件寫明時間與地點。

## 機制、數值、經濟（模擬器類作品才需要）
- 核心循環：玩家每個回合大致在做什麼、做完得到什麼。每一項都要接得到變數，接不到的活動只當氣氛。
- 只追蹤會變的值，每個值只在當下看得到的事件更新。
- 成長用累計值加一張等級表：每件事加一個寫死的數（「完成同級任務 +2、高一級 +3、低一級 +1」），累計值只加不歸零，等級照表寫（「累計 10 是 2 級、25 是 3 級、45 是 4 級」）。同一個理由不重複計分，單則回覆設增減上限。
- 價目表放作品設定，變數只存結果。
- 餘額可以是負數，代表欠費，下一期先追繳；數字變數的最小值要改成負數。
- 等級與權限用表格：每一級解鎖什麼、限制什麼。
- 難度是遊戲外的設定，角色不知道也不會問玩家。沒指定走預設，玩家明說才用另一個。每種難度的日期、資源、狀態寫在開局章節的私設，不寫進作品設定；初始值只在新聊天的第一則回覆校準一次。
- 外部（例如別的模型）提的漏洞，先看修正會不會讓規則變複雜，用最小的改法補，或判斷不值得補。

# 設定集（lorebook）
設定集只在最近的對話出現關鍵字時才送進模型，不計入 30,000 字。偶爾才用到的東西放這裡，隨時都要的放作品設定或角色卡。

## 四種條目
每部作品的設定集由這四種組成，一條一個題材，500 字內，寫整場遊戲都成立的事。內容可以用 {{user}}、{{char1}} 這類替換符號。

1. **濃縮角色設定**：給沒有角色卡的角色用，一個人一條，關鍵字用他的名字與別人對他的稱呼。雖然沒有卡，該有的資料還是要有：年齡、身高、外貌、職業、與 {{charN}} 和 {{user}} 的關係、經歷過什麼。寫到人的感受時一樣寫到感受與傾向為止。有角色卡的角色不另外做這種條目，卡上的內容不重複放進設定集。
2. **物品設定**：一樣物品一條。寫它是什麼、長什麼樣子、怎麼用、誰持有、在這個世界裡代表什麼。
3. **地點設定**：一個地方一條，它的作用是地圖，最主要寫佈局，建築物照樓層寫。
   - 戶外或一整片區域照分區寫：東側是什麼、中央是什麼、哪條路通到哪裡。
   - 佈局是清單，可以條列；擺設與氛圍用句子寫。
   - 一個地方的佈局太長時拆成多條（整棟的總覽一條，內容多的樓層各一條），各自帶關鍵字。
4. **細節補充**：作品設定與角色卡放不下、偶爾才需要的細節，例如組織、制度的細則、過去的事件。

## 關鍵字與拆法
- **關鍵字用玩家實際會打的詞**（「銀劍」，不是「銀劍的由來」）；寫法有好幾種就全部登錄。
- **避開太常見的詞**（「他」「學校」），常見詞會一直占送入的名額。
- **重要的條目在套用清單排上面**，同時命中時才不會被擠掉。
- **長設定依主題拆成多條**，各自帶關鍵字（王都・地理、王都・歷史、王都・王室）。硬縮成一條，一個詞就把所有內容整個帶進來。
- **分層**：深層條目的關鍵字要出現在淺層條目的內容裡，玩家才會一步步摸到。

## 放設定集，還是放別處？
用「是不是隨時都需要」來分：隨時都要的放作品設定或角色卡，偶爾才用到的放設定集。完整的對照在 `SKILL.md` 的「每件事寫在哪」。

## 官方的運作規則
- 先建在帳號的設定集庫（每帳號 2,000 條），再逐部作品套用（每部 200 條）。結構和圖片庫相同；同一條可套用到多部作品。
- 儲存作品後才反映到對話。在設定集庫修改條目後，也必須重新儲存作品，對話讀取的是儲存當時的內容。
- 從設定集庫刪除條目，所有套用它的作品也會一併移除。登入前的體驗對話不送入設定集。作品已翻譯時，關鍵字同時以原文與譯文搜尋。

**上限**
| 項目 | 上限 |
|---|---|
| 標題 | 50 字 |
| 關鍵字 | 每條 1～20 個，每個 2～60 字，逗號分隔 |
| 內容 | 500 字，超過無法儲存 |
| 套用到作品 | 每部 200 條，套用清單可拖曳調整順序（上面先送入） |

**什麼時候送入**
- 搜尋範圍：剛送出的訊息與前 5 則訊息（含 AI 回覆）。更早的詞不會觸發。
- 每回合最多 6 條；多條同時命中依套用順序從上往下。
- 已送入的條目留在對話中，不重複送入；長對話整理上下文後，會重新搜尋並送入。
- 比對：韓文只要句子裡包含就命中，英文以單字為單位，不分大小寫與全形／半形。中文官方沒有另外寫，實際用起來和韓文一樣是包含式（「騎士」會被「騎士團」「騎士食堂」命中，所以要用更獨特的詞）。不支援正規表達式或萬用字元。

**沒有送入時，依序檢查**
1. 套用後有沒有儲存作品。2. 關鍵字是否 2 個字以上。3. 最近 5 則訊息裡有沒有真的出現關鍵字。4. 已送入的條目不會重複送入。

**用 MCP 編輯**
- 找條目：`lorebook_list_library`（`summary_only: true`）→ `lorebook_get_entry` → `lorebook_patch_entry` 只送改的欄位。
- 設定集庫的改動在使用者於 Studio 存檔後才進到對話；存檔前，草稿裡套用的副本可能還是舊的。要讓草稿副本立刻更新，先 `lorebook_detach_from_workspace_draft` 再 `lorebook_attach_to_workspace_draft`（實測）。

# 秘密與真相揭露
一般作品不需要另外設計：秘密的揭露跟著章節或變數走，平常的反應與怎麼帶開寫在角色卡的「認知範圍」，要鎖住的內容放章節私設。不為一般作品額外開知情進度變數。

只有作品真的以解謎、隱瞞為核心時，才加下面這些，挑用得到的：
- **什麼算確實知道**（寫在作品設定）：親眼看到、拿到實物或文件、知情的人當面明說並附上可驗證的東西才算。傳聞、猜測、直覺、好感高低都不算。某個角色親口說出算不算，先問使用者。
- **不能一步到位**：察覺異常、取得線索、確實知道是三件事，不在同一則完成，也不在第一次互動就發生。真相有好幾層時，一次只揭開一層。知道了就不會變回不知道。
- **誰能知道什麼**（寫在作品設定）：依角色的身分規定各自能知道的範圍。作者知道不等於角色知道。
- **記在變數裡**，需要才設，擇一：
  1. 每個角色一格，只標已經知道或還不知道。
  2. 一串狀態詞（未察覺、起疑、已確認、已坦白），每個轉換寫一件看得見的事當條件，不可回退。
  3. 重大事項帳本，格式「內容｜持有人｜狀態」，只記會改變後續互動的事。
