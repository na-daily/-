# 世界觀、作品設定、設定集、秘密
> 設定集的運作與上限是官方規則，其餘是這套工作流的做法。

# 世界觀怎麼寫
世界觀是寫給模型的運作規則。每一句寫玩家實際會碰到的事：看得到什麼、能做什麼、要付出什麼。

## 先分清五件事
動筆前把這五件事各自定好，寫的時候也分開寫。

1. **這是什麼樣的虛構世界**。一句話：它是哪一類的世界，加上它和同類最不一樣的那一點。
2. **參照的時代與地區**。這個世界以哪個年代、哪個國家或地區為底：服裝、建築、飲食、稱謂、貨幣、科技到哪裡。混合好幾種時，寫清楚哪一塊照哪一個。開局的年份也在這裡定，近未來或未來題材放未來的年份。
3. **超出現實的東西**。有沒有魔法、異能、超自然、超前的科技。
   - 有的話，每一種寫六樣：它是什麼、誰擁有、做得到什麼、做到哪裡為止、要付什麼代價、一般人怎麼看待它。當事人離場時怎麼處理也寫上。
   - 都沒有的話寫一句：這個世界照現實的物理運作。
4. **世界的要素**。玩家會用到、會被它管到的東西，一樣一節，用得到的才開。常見的有：
   - 社會與階層：分成哪幾層、各層怎麼過日子、怎麼往上爬。
   - 錢與謀生：靠什麼賺錢、日常開銷、出門吃飯看病各要多少、進哪些地方要什麼門檻。
   - 制度與法律：身分、婚姻與伴侶、犯了事怎麼處理、誰來執行。
   - 組織與勢力：有哪些、各自要什麼、彼此的關係。
   - 通訊與交通：人怎麼聯絡、怎麼移動、要多久。
   - 這部作品的玩法用到的系統。
5. **每個區域的法則**。這個世界分成哪幾區。每一區寫：方位、看起來的樣子、誰住在那裡或在那裡活動、怎麼進出，以及這一區自己的規矩（什麼在這裡行得通、什麼會惹上麻煩、誰說了算）。

## 寫出來的樣子
照這個順序排。括號裡是那個位置要寫的內容，標題換成這部作品自己的名稱。

```
# 世界觀
（第一段）這是什麼地方。參照的時代與地區。有哪些超出現實的東西。走在街上看得到什麼。
（第二段）一般人怎麼過日子、靠什麼活。有權有錢的人怎麼過日子、拿這個世界來做什麼。
（第三段，有才寫）這個世界特有的制度，以及它讓日常多出哪些規矩和後果。

## （超出現實的東西，一種一節）
（一段）它是什麼、誰擁有、平常怎麼用。
- 做得到的事：
- 做到哪裡為止：
- 代價：
- 一般人怎麼看待它：

## （世界的要素，一樣一節）
（一段）它怎麼運作、誰在用。
- （一條一件事：價錢、門檻、誰用得起、出問題會怎樣）

## 區域
（一句）整體怎麼分、區和區之間怎麼來往。
- （方位）「區名」：看起來的樣子；誰在這裡；怎麼進出；這裡的規矩。
```

每一句照這幾條寫：
1. **一句寫一個事實**，句型是「誰或什麼，在什麼情況，會怎樣」。
2. **數量、價錢、時間、人數都寫出數字或範圍**。
3. **一件事的途徑有限時，把途徑全部列出來**，句型是「只有這幾種：…」。
4. **一節是一段加上幾條細項**。一段講運作，細項一條一件事。
5. **參照的時代與地區本來就有的東西，交給模型補**；這裡寫的是這個世界和它不一樣的地方。
6. **歷史、年表、玩家碰不到的遠方勢力放設定集**；這個世界的由來，在玩家碰得到它留下的東西時，寫進對應的那一節。

## 地點
**地點是地圖，最主要寫佈局**：分成哪幾區、各在哪個方位、裡面有什麼、彼此怎麼連通、從哪裡進出。建築物內部照樓層寫（一樓有什麼、二樓有什麼），一層一行。佈局之後再補擺設、光線聲音氣味溫度、常出現的人和他們在做什麼。地點寫成佈局與樣子；主要角色在那裡的反應寫在角色卡。

# 作品設定 `detailMd` 的骨架
依作品增減，每段只寫整場遊戲都成立的內容。**順序固定：世界是主，內容怎麼描寫是輔，所以世界在前、寫法在後**：
1. **世界觀**：照「寫出來的樣子」，開頭兩三段，底下超出現實的東西、世界的要素各一節，最後是「區域」。
2. **各項規則**（有才寫）：世界本身以外的規則，一項一節（玩法的流程、指令、關係怎麼確認）。解謎、隱瞞為核心的作品，「什麼算確實知道、誰能知道什麼」也放這裡。
3. **變數**：更新總則一句，加上這部作品特有的更新例外。
4. **運作與敘事**：敘事指示。
5. **親密時的描寫**（成人向才有）：親密場面怎麼寫，接在運作與敘事後面。

整理既有作品的順序時只搬位置、不順手改內容，搬完核對字數有沒有變。「運作與敘事」裡的舊句另外對齊敘事指示的句子。

- **作品掛在共用的世界底下時，骨架第 1 項不重寫世界**。世界的設定每次對話都會自動帶入，`detailMd` 從這部作品自己的設定寫起。
- {{user}} 和角色有關的部分（例如只有 {{user}} 能安撫他）寫在角色卡。
- 單一主要角色的作品，他的出沒寫在角色卡；{{user}} 的身分普通時在開場交代；旁人對 {{user}} 有特別的立場時才寫「各方的態度」。
- **會反覆使用的流程，沒有其他章節可以切回去時，直接寫在作品設定**（例如只有「出任務」一套流程的作品）。之後作品有了別的章節，再把它搬成章節。
- 作品設定計入 30,000 字，全部寫在這裡會擠掉角色與開場的額度。

## 世界結構的清單（需要才寫）
- **陣營對照表**：兩個以上的陣營，用表格比較居民、行事風格、玩家的體驗。反差越清楚，模型越不會把兩邊演成一樣。
- **角色出沒表**（多角色的作品才列）：每個角色平常在哪、什麼時候去哪。
- **日程**：固定的週期事件寫明時間與地點。

## 自查
- 五件事都分開寫了嗎：什麼樣的世界、參照的時代與地區、超出現實的東西、世界的要素、每個區域的法則？
- 超出現實的東西，每一種都寫了做得到什麼、做到哪裡為止嗎？
- 每一句都是玩家會碰到的事實嗎？數字都寫出來了嗎？
- 每一區都寫了它自己的規矩嗎？
- 地點有沒有寫出分區、方位與怎麼連通？

# 設定集（lorebook）
設定集只在最近的對話出現關鍵字時才送進模型，不計入 30,000 字。偶爾才用到的東西放這裡，隨時都要的放作品設定或角色卡。

## 四種條目
每部作品的設定集由這四種組成，一條一個題材，500 字內，寫整場遊戲都成立的事。內容可以用 {{user}}、{{char1}} 這類替換符號。

1. **濃縮角色設定**：給沒有角色卡的角色用，一個人一條，關鍵字用他的名字與別人對他的稱呼。雖然沒有卡，該有的資料還是要有：年齡、身高、外貌、職業、與 {{charN}} 和 {{user}} 的關係、經歷過什麼。寫到人的感受時一樣寫到感受與傾向為止。有角色卡的角色不另外做這種條目，卡上的內容不重複放進設定集。
2. **物品設定**：一樣物品一條。寫它是什麼、長什麼樣子、怎麼用、誰持有、在這個世界裡代表什麼。
3. **地點設定**：一個地方一條，照上面「地點」寫。
   - 戶外或一整片區域照分區寫：東側是什麼、中央是什麼、哪條路通到哪裡。
   - 佈局是清單，可以條列；擺設與氛圍用句子寫。
   - 一個地方的佈局太長時拆成多條（整棟的總覽一條，內容多的樓層各一條），各自帶關鍵字。
4. **細節補充**：作品設定與角色卡放不下、偶爾才需要的細節，例如組織、制度的細則、過去的事件。

## 關鍵字與拆法
- **關鍵字用玩家實際會打的詞**（「銀劍」，不是「銀劍的由來」）；寫法有好幾種就全部登錄。
- **避開太常見的詞**（「他」「學校」），常見詞會一直占送入的名額。
- **重要的條目在套用清單排上面**，同時命中時才不會被擠掉。
- **長設定依主題拆成多條**，各自帶關鍵字（王都・地理、王都・歷史、王都・王室）。硬縮成一條，一個詞就把所有內容整個帶進來。
- **分層**：深層條目的關鍵字要出現在淺層條目的內容裡，玩家才會一步步摸到。

## 官方的運作規則
- 先建在帳號的設定集庫（每帳號 2,000 條），再逐部作品套用（每部 200 條）。結構和圖片庫相同；同一條可套用到多部作品。
- 儲存作品後才反映到對話。在設定集庫修改條目後，也必須重新儲存作品，對話讀取的是儲存當時的內容。
- 從設定集庫刪除條目，所有套用它的作品也會一併移除。登入前的體驗對話不送入設定集。作品已翻譯時，關鍵字同時以原文與譯文搜尋。

**上限**
| 項目 | 上限 |
|---|---|
| 標題 | 50 字 |
| 關鍵字 | 每條 1～20 個，每個 2～60 字，逗號分隔 |
| 內容 | 500 字，超過無法儲存 |
| 套用到作品 | 每部 200 條，套用清單可拖曳調整順序（上面先送入） |

**什麼時候送入**
- 搜尋範圍：剛送出的訊息與前 5 則訊息（含 AI 回覆）。更早的詞不會觸發。
- 每回合最多 6 條；多條同時命中依套用順序從上往下。
- 已送入的條目留在對話中，不重複送入；長對話整理上下文後，會重新搜尋並送入。
- 比對：韓文只要句子裡包含就命中，英文以單字為單位，不分大小寫與全形／半形。中文官方沒有另外寫，實際用起來和韓文一樣是包含式（「騎士」會被「騎士團」「騎士食堂」命中，所以要用更獨特的詞）。不支援正規表達式或萬用字元。

**沒有送入時，依序檢查**
1. 套用後有沒有儲存作品。2. 關鍵字是否 2 個字以上。3. 最近 5 則訊息裡有沒有真的出現關鍵字。4. 已送入的條目不會重複送入。

**用 MCP 編輯**
- 找條目：`lorebook_list_library`（`summary_only: true`）→ `lorebook_get_entry` → `lorebook_patch_entry` 只送改的欄位。
- 設定集庫的改動在使用者於 Studio 存檔後才進到對話；存檔前，草稿裡套用的副本可能還是舊的。要讓草稿副本立刻更新，先 `lorebook_detach_from_workspace_draft` 再 `lorebook_attach_to_workspace_draft`（實測）。

# 秘密與真相揭露
一般作品不需要另外設計，也不額外開知情進度變數。

只有作品真的以解謎、隱瞞為核心時，才加下面這些，挑用得到的：
- **什麼算確實知道**（寫在作品設定）：親眼看到、拿到實物或文件、知情的人當面明說並附上可驗證的東西才算。傳聞、猜測、直覺、好感高低都不算。某個角色親口說出算不算，先問使用者。
- **一步一步來**：察覺異常、取得線索、確實知道是三件事，各佔一則以上，從第二次互動之後才開始。真相有好幾層時，一次只揭開一層。知道了就不會變回不知道。
- **誰能知道什麼**（寫在作品設定）：依角色的身分規定各自能知道的範圍。作者知道不等於角色知道。
- **記在變數裡**，需要才設，擇一：
  1. 每個角色一格，只標已經知道或還不知道。
  2. 一串狀態詞（未察覺、起疑、已確認、已坦白），每個轉換寫一件看得見的事當條件，不可回退。
  3. 重大事項帳本，格式「內容｜持有人｜狀態」，只記會改變後續互動的事。
