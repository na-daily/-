# 平台規範：上限、發布、公開
> 官方規則。數字以 `workspace_get_content_budget` 與工具報錯為準；欄位、工具與 Cinema 的細節以 MCP 的創作指南為準。

## 欄位上限與作品字數 30,000 字

| 欄位 | 上限 | 數量 | 計入 30,000 字 |
|---|---|---|---|
| 標題・標語 | 20 字・100 字 | 1 | 否 |
| 作品設定（detailMd） | 20,000 字 | 1 | 是 |
| 角色名稱 | 15 字 | 最多 10 個角色 | 是 |
| 角色公開卡・`secret` | 各 20,000 字 | 每個角色 | 是 |
| 開場 | 每個 20,000 字 | 1～5 個 | 是，只算最長的那一個 |
| 起手式 | 每個 200 字 | 每個開場 0～3 個 | 是，只算最長那個開場的起手式 |
| 範例對話 | 5,000 字 | 最多 5 | 是 |
| 變數 | 名稱 10、說明 5,000、範圍 5,000、初始值 200 字 | 最多 10 | 是 |
| 章節標題・切換條件 | 20 字・200 字 | 每個章節 | 是 |
| 圖片群組名稱・圖片說明 | 50 字・100 字 | 群組 50、圖片 500 | 是 |
| 章節內文・章節私設 | 各 2,000 字 | 每章，最多 20 章 | **否** |
| 設定集 | 每則 500 字 | 每部 200 則 | **否** |
| 介紹頁 | 50,000 字 | 1 | **否** |
| 創作者留言（creatorNotes） | 20,000 字 | 1 | **否** |

- 作品掛在「世界」底下時，世界的設定和作品一起算進 30,000 字。
- 角色最多 10 個，用 `{{char1}}`～`{{char10}}` 依角色順序編號，順序變動編號就跟著變。
- 字數滿出來時，先把偶爾才用到的設定搬進設定集、把只在某一段用到的內容搬進章節私設，這兩處都不計入字數。

## 發布條件
缺任何一項，公開按鈕都會被擋。章節與範例對話不是必要的（實測：沒有章節、沒有範例對話的作品可以公開）。

| 步驟 | 需要 |
|---|---|
| 個人資料 | 標題、標語；至少 1 名角色，有名稱、介紹與頭像 |
| 對話 | 開場 |
| 圖庫 | 至少 1 張圖庫圖片、縮圖 |
| 公開設定 | 至少 1 個分類、至少 1 個標籤；介紹頁至少 100 字；測試對話 10 次；標示二次創作時填原作標題 |
| 全部 | 作品字數 30,000 字以內（超過連儲存都會被擋） |

- **測試對話**：在同一間聊天室對自己的作品傳 10 次即可，自動出現的開場不計次數，用基本模型時前 10 次免費。看不到聊天按鈕時，先按編輯畫面下方的「建立作品」（以不公開狀態建立）。MCP 只能改草稿，這一步請使用者在 Studio 做。
- **分類與標籤**：分類最多 3 個，用官方顯示名稱，對照 MCP 的分類表；標籤 1～15 個。
- **創作者留言**：玩家看得到、會被審查（標準與介紹頁相同），AI 不會讀，只放狀態面板用法、可重新回覆這類簡短說明。

## 公開範圍
| 設定 | 誰看得到 |
|---|---|
| 公開 | 所有人，出現在列表與搜尋 |
| 連結公開 | 只有知道網址的人 |
| 不公開 | 新使用者看不到；已在對話的人可繼續使用 |

- 第一次公開的時間會反映在新作與急上升，所以準備好再第一次公開。
- 公開後的修改在儲存後立刻生效，進行中的聊天室會參考累積的對話，所以改完要開新聊天室確認。

## 官方指南裡這套工作流不照的部分
MCP 創作指南裡的寫作建議（開場寫 `{{user}}`、從緊繃時刻切入、必寫 3 個以上主線章節、必放 2～5 則範例對話）是給從零呼叫 `story_create_draft` 的一般使用者的，這套工作流照自己的寫法。使用者明說要用 `story_create_draft` 新建草稿時，才受那個工具的必填下限限制。

## `world`
- `world`（字串欄位，最多 4,000 字）：world＝世界觀概要及作品背景資訊，在作品設定之前，只有MCP工具可讀寫。
- `workspace_get_draft` 回傳 `world` 物件時，作品掛在一個 Tikita 世界底下。世界是創作者在好幾部作品之間共用的設定，在 Tikita App 的「創作 > 世界」編輯，MCP 只能讀。世界的設定每次對話都會送進模型，所以作品設定只寫這部作品自己的設定，要改世界時把文字整理給使用者，請他到 App 裡改。
