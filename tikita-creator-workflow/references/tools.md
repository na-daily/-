# 工具的坑與圖庫
> 工具怎麼用以 MCP 的工具說明與創作指南為準，這裡只記實測過、說明裡沒寫清楚的地方。

## 寫入前後
- 使用者在 Studio 改過的內容以 Studio 為準，所以寫入前先讀最新版；Studio 存檔後 item id 會變，要重新列一次。
- 只改長欄位裡的一小段時用 `workspace_replace_text`，`find` 要照原文的全形標點（「：」不是「:」）。
- 中文直接寫，不轉成 `\u` 跳脫碼，因為跳脫過的字很容易打錯成形近字。寫完讀回那一欄對照。
- 改設定集庫的條目後，草稿裡套用的副本要等使用者存檔才會更新；要立刻更新時，先從草稿卸下再套用一次。

## MCP 說明沒寫的
- 調整角色卡的順序會改變 `{{char1}}`、`{{char2}}` 的編號，所以調序後檢查開場與範例對話。
- 頭像的更換與裁切、秘密圖片的解鎖條件，官方建議在作品編輯畫面調整。

## 圖庫
- **AI 照群組名稱與圖片說明選圖**，所以群組依地點、時間、氛圍取名（辦公室／夜晚／爭吵），說明寫成一句「下雨的夜晚，熄燈的辦公室」。名稱與說明計入 30,000 字，圖多時寫短。不在對話裡用的圖（封面、頭像）另外放一組。
- 未分類圖片超過 50 張就無法儲存，想不到名稱時建一個「其他」群組。
- **秘密圖片**：要在圖庫點開圖片的「編輯圖片」視窗把秘密打開，解鎖費用與最低解鎖條件的欄位才會出現；只按卡片上的切換鈕會用預設值（50 Tik、無對話次數條件）設成秘密。
- 縮圖屬於公開區，照公開區的標準。
- 圖片被自動判定攔下時，用圖片庫的筆刷遮住後儲存。
