# 工具的坑與圖庫
> 工具怎麼用以 MCP 的工具說明與創作指南為準，這裡只記實測過、說明裡沒寫清楚的地方。

## 寫入前後
- 使用者在 Studio 改過的內容以 Studio 為準，所以寫入前先讀最新版；Studio 存檔後 item id 會變，要重新列一次。
- 只改長欄位裡的一小段時用 `workspace_replace_text`，`find` 要照原文的全形標點（「：」不是「:」）。
- 中文直接寫，不轉成 `\u` 跳脫碼，因為跳脫過的字很容易打錯成形近字。寫完讀回那一欄對照。
- 改設定集庫的條目後，草稿裡套用的副本要等使用者存檔才會更新；要立刻更新時，先從草稿卸下再套用一次。

## `workspace_patch_draft` 的陣列
陣列整個取代，所以省略的項目會消失。
- 角色：比對到的角色省略的欄位（名稱、介紹、`secret`、性別、年齡、頭像、語音）都保留原值，給空字串才清空。只改一段文字時用 `workspace_replace_text` 或 `workspace_patch_item`。
- 章節：每個舊章節都帶齊 `id`、`originId`、`display_order`、`title`、`body_md`、`secret`、`transition_condition`，以及 Studio 存檔後多出的背景圖欄位；漏送 `originId` 會斷掉和正式版章節的連結。`unlock_hint` 省略時保留原值、給空字串會清除，只改它時用 `workspace_patch_item`。送完立刻讀回比對。
- 範例對話、變數、圖片這幾個陣列沒有防呆，省略就會消失。
- 調整角色卡的順序會改變 `{{char1}}`、`{{char2}}` 的編號，所以調序後檢查開場與範例對話。

## 要在作品編輯畫面做的事
- 頭像的更換與裁切、推薦角色模板、秘密圖片的解鎖條件：官方建議直接在作品編輯畫面調整。
- 共用世界觀的連結與解除：到「創作」的世界觀頁面。
- 推薦模型與翻譯備註可以用 `workspace_update_story_metadata` 改；傳入這個工具改不了的欄位時，回覆會列出哪些被略過。作品的譯文照既有的翻譯流程更新。
- MCP 改的都先存在草稿，要使用者在作品編輯畫面確認後按「儲存」才套用。

## 圖庫
- **AI 照群組名稱與圖片說明選圖**，所以群組依地點、時間、氛圍取名（辦公室／夜晚／爭吵），說明寫成一句「下雨的夜晚，熄燈的辦公室」。名稱與說明計入 30,000 字，圖多時寫短。不在對話裡用的圖（封面、頭像）另外放一組。
- 未分類圖片超過 50 張就無法儲存，想不到名稱時建一個「其他」群組。
- **秘密圖片**：要在圖庫點開圖片的「編輯圖片」視窗把秘密打開，解鎖費用與最低解鎖條件的欄位才會出現；只按卡片上的切換鈕會用預設值（50 Tik、無對話次數條件）設成秘密。
- 縮圖屬於公開區，照公開區的標準。有中日韓文字標題的封面，先生無字的底圖，文字在外部排版。
- 圖片被自動判定攔下時，用圖片庫的筆刷遮住後儲存。
