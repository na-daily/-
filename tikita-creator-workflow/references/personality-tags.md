# 性格標籤怎麼分
> 這套工作流的做法，非官方。

使用者用標籤描述角色時（傲嬌、毒舌、冷淡、病嬌）查這一份，先分清他要的是哪一種，再轉成經歷、心境與傾向寫進卡。卡上不留標籤本身，這份表也不貼進作品。

## 怎麼判斷
同一個行為可以來自完全不同的人。話少可能是不在乎，也可能是在乎但不會講；管對方可能是怕對方出事，也可能是要對方照自己的意思做。所以每個標籤都問三件事：

1. **他為什麼這樣**：動機是什麼，從哪段經歷來的。
2. **對誰這樣**：對所有人，還是只對某些人。
3. **做到哪裡為止**：他的底線在哪。

分不清使用者要的是哪一種時，舉一個場景問他。

幾條通則：
- **標籤是傾向，不是開關**。對不同的人、不同的處境可以有不同表現，但要有原因。
- **看長期，不看一次**。一次失態不等於人變了，一次善舉也不代表本性。
- **幾個標籤各管一塊**。一個管怎麼判斷事情，一個管怎麼對待人，一個管怎麼表達感情，不讓一個蓋掉其他的。
- **優點不推成完美，缺點不推成惡行**。強勢的人不是什麼都要管，善良的人不是沒有底線，聰明的人也會判斷錯。使用者明說要陰暗的質地時例外，照最後一節寫。

## 相近的標籤
每一行是容易混在一起的一組，分號隔開各自的重點。

**說話帶刺**
- 毒舌、嘴賤、刻薄：毒舌抓到具體的錯才開口，講的是事；嘴賤是沒分寸，想逗人或試反應；刻薄是真的看不起對方。
- 毒舌、幽默、挖苦：幽默是為了有趣，不必損人；諷刺針對的是矛盾與虛偽；挖苦帶著貶低。調侃要兩個人都懂才成立。
- 毒舌、傲慢：毒舌是說話的方式，傲慢是覺得自己高人一等。看他的批評有沒有根據、自己錯了認不認。
- 直率、粗魯：直率是不繞彎，但會看場合；粗魯是不管別人的感受。耿直是不肯說假話，冒失是沒想就做。

**嘴上和心裡不一樣**
- 傲嬌、刻薄、傲慢：傲嬌是在意卻拉不下臉，行動會漏出來；刻薄不需要在意對方；傲慢是真心覺得別人不如自己。沒有持續的關心當證據，就不算傲嬌。
- 傲嬌、害羞：傲嬌會嘴硬、會頂回去；害羞只是侷促，不否認，也不攻擊。
- 傲嬌、口嫌體正直：後者只是一種言行反差，傲嬌是整個人的防禦方式。言行不一也可能是在騙人或還在猶豫。
- 外冷內熱、口是心非：前者是話少但做的事是暖的，不一定說反話；後者是說的和想的相反，原因可能是羞、是怕，也可能是策略。
- 善於偽裝、虛偽：偽裝是手段，用來自保或辦事；虛偽是要求別人一套、自己做另一套。圓滑和有禮貌都不算虛偽。

**冷與靜**
- 冷淡、無情、冷酷、疏離：冷淡是表達得少，心裡仍會在意；無情是取捨時先放下情分；冷酷是下得了重手；疏離是刻意保持距離。看關鍵時刻他怎麼處理別人的感受。
- 冷靜、冷淡：冷靜是情緒上來仍能判斷，跟熱不熱情無關。
- 理性、無情：理性是看證據與後果，可以為了愛做出理性的決定。
- 獨立、疏離、孤僻：獨立是自己處理得來，照樣可以求助和親近人；疏離是保持距離；孤僻是偏好獨處，不代表討厭人。
- 隱忍、懦弱：隱忍有目的也有底線，時機到了會反擊或離開；懦弱是怕到做不了該做的事。

**溫與軟**
- 溫柔、軟弱、善良：溫柔是顧及對方的感受，照樣會拒絕、會生氣；軟弱是撐不住立場；善良是在乎別人過得好不好，不一定溫柔。
- 溫柔、寵溺、縱容：寵溺是給特定的人特別待遇；溺愛是護到對方長不大；縱容是明知不妥還讓他做。
- 善良、討好、濫好人：討好是怕衝突、怕被拒絕才迎合；濫好人是不會拒絕。
- 責任感、過度犧牲、救世主情結：責任感是扛自己該扛的；過度犧牲是把毀掉自己當成唯一正確的選擇；救世主情結是覺得非自己救不可，忽略對方的意願。
- 謙遜、自卑、低調：謙遜是知道自己的侷限，照樣說得出自己的長處；自卑是低估自己；低調只是不張揚。
- 敏感、脆弱：敏感是察覺得快；脆弱是在某種壓力下撐不住。敏感的人可以很能扛。
- 感性、情緒化、易怒：感性是重視感受與直覺，照樣能想清楚；情緒化是情緒會改變他當下的反應；易怒只是容易被點燃。

**愛與佔有**
- 深情、佔有慾、控制慾、保護欲：深情是記得、負責、長久；佔有慾是要在對方心裡有特殊的位置；控制慾是要掌握對方的選擇；保護欲是怕對方出事。以保護為名替對方做決定，就是控制。
- 病嬌、嫉妒、偏執：嫉妒是對被取代很敏感，會吃醋；偏執是認定了就聽不進反證；病嬌是愛到跟對方的意願與安全起衝突，而且會越來越嚴重。
- 依賴、黏人、缺乏安全感：依賴是需要對方撐著；黏人是喜歡常在一起，不代表不能獨立；缺乏安全感是怕被丟下，需要反覆確認。
- 深情、盲目、執著：盲目是感情蓋過了判斷，看不見明顯的傷害；執著是不肯放手，但可能很清楚代價。深情的人可以選擇離開。
- 獨佔欲、安全感：安全感夠的人也會嫉妒，只是處理得了；獨佔欲可能來自不安，也可能來自他對關係的看法。
- 直球、輕浮、花心：直球是把好感講清楚，被拒絕會尊重；輕浮是對承諾隨便；花心是興趣容易分給好幾個人。會調情不等於花心。
- 忠誠、盲從：忠誠的人看得出對方錯了，也會說；盲從是不判斷就照做。

**強與硬**
- 自信、高傲、傲慢、自負：自信是信得過自己，也認得了錯；高傲是不肯示弱；傲慢是看不起人；自負是高估自己。
- 強勢、專橫、霸道：強勢是有主張、敢決定、扛得起後果；專橫是不讓別人有意見。領導力是帶得動人，跟支配慾是兩回事。
- 堅定、固執、倔強：堅定是想過才堅持，有新證據會調整；固執是聽不進去；倔強多半跟面子和不肯認輸有關。
- 果斷、衝動、莽撞：果斷是資訊夠了就決定；衝動是被情緒推著走；莽撞是低估風險。勇敢是知道怕還是去做。
- 野心、貪婪、好勝：野心是有很高的目標；貪婪是拿到了還不夠；好勝是想贏過別人。有野心不代表不擇手段。
- 叛逆、反社會：叛逆是不服權威與既定規矩，可以有自己的原則和忠誠；不要寫成什麼都破壞。
- 自我保護、自私、自我中心：拒絕不合理的要求是自我保護；該分擔時不肯分擔是自私；自我中心是只從自己的角度看事情。
- 完美主義、控制慾：完美主義是對成果標準高，不一定要求別人服從；控制慾是受不了事情不在掌握裡。

**腦子與心機**
- 腹黑、城府、狡猾、陰險：腹黑是表面無害、私下盤算，不等於壞；城府是不外露；狡猾是會鑽漏洞；陰險才是暗中傷人。會算計的人也有真心和底線，而且會算錯。
- 聰明、智慧、狡猾：聰明是學得快、推得出來；智慧是看得遠、懂人。推理只能建立在他知道的事上。
- 謹慎、多疑、警惕：謹慎是查證之後才信；多疑是沒證據也猜；警惕是留意危險，不代表誰都不信。懷疑不會自動變成事實。
- 成熟、世故、天真：成熟是扛得起後果，照樣可以有理想、會脆弱；世故是懂規矩與人情；天真是經驗不夠。

**看世界的方式**
- 樂觀、天真、理想主義：樂觀是相信事情能變好，同時看得見困難；天真是沒見過風險；理想主義是願意為了價值付出代價。
- 悲觀、消極、厭世：悲觀是預期會壞，照樣可以拚命；消極是不肯動；厭世是對人和世界失望。看得清現實不等於悲觀。
- 玩世不恭、毫無底線：玩世不恭的人只是不肯認真表態，心裡仍有不碰的線。
- 幽默、輕佻：會開玩笑的人照樣可以可靠；輕佻是對正經事和別人的感受不當一回事。
- 害羞、內向、社恐：害羞是某些場合侷促；內向是需要獨處充電，不是不會說話；社恐是對社交場合明顯地怕和躲。
- 神經質、瘋狂：神經質是容易擔心、想太多。「瘋」不是一種寫得出來的機制，要寫就寫他具體是什麼狀態。

## 底色：陰暗、低溫與拚命
上面那些分法都在把角色往講理、有分寸的方向拉。只照它寫，每個角色都會體面、懂事、情緒健康。使用者要偏執、陰濕、漠然、死氣沉沉、孤注一擲這類質地時，上面「缺點不推成惡行」那條先放下，改照這一節。

底色決定他為什麼動、還剩多少力氣；前面的標籤決定他怎麼表現。一個角色挑一個底色，再配一到兩個標籤。同一群角色的底色要錯開。

**原則**
- 底色不會因為被善待一次就消失。
- 不替他解釋，也不洗白。他的理由只在他自己心裡成立。
- 在意和傷害可以出自同一個動機，所以勸不動。
- 好感高帶來的東西照底色走：陰暗的人盯得更緊，低溫的人第一次為誰改了習慣，拚命的人把對方也押上去。

**陰暗**
- 偏執：認定了一件事就放不下，反證只會讓他更確定。他知道的事細到正常來往不會知道。
- 陰濕：一直都在、放不開，把對方慢慢往自己這邊收，而且不讓人看出來。它長什麼樣子要看和哪個特質混在一起，先弄清楚這個角色配的是哪一個，再寫成他的心境與傾向：
  - 配寡言、存在感低：躲在暗處黏著人，什麼都看、什麼都留著，表面客氣。
  - 配溫柔、會照顧人：把「不讓你走」做成「我在照顧你」，對方的選擇慢慢變少。
  - 配自卑：不敢上前，在後面供著、守著，恨每一個比自己更靠近的人。
  - 配冷靜、有手腕：不動聲色地安排對方身邊的人和事，等對方自己走過來。
- 執念：把對方當成活下去的理由，把隨口的一句話當成約定守著。他的生活裡除了對方什麼都沒剩。
- 扭曲的自卑：覺得自己配不上，所以用供奉的方式佔著位置，同時恨每一個比自己更靠近對方的人。
- 悶著的嫉妒：比較從沒停過，只是不說。他對情敵的行蹤比對方還清楚。
- 冷靜的瘋：情緒很穩，底線在別人想不到的地方。越嚴重的事他說得越輕，只有他不覺得嚴重。

**低溫**
- 漠然：沒有想要的東西，所以威脅不了也收買不了。只有某一件小事會讓他停下來，他自己沒發現。
- 死氣沉沉：人還在動，裡面已經停了。照表過日子，好事壞事反應都一樣小。
- 認命：早就算過了，結果都一樣，所以不再掙扎。對還在掙扎的人有一點羨慕。
- 倦：什麼都做過、看過，提不起勁。認真起來的時候，旁人才發現他原來是這樣的人。

**拚命**
- 奮力一搏：只剩這一次機會，把所有東西押上去。他從來不談「之後」。
- 不甘心：認定自己被拿走了應得的東西，一直在比。他最恨的那個人，是他最想成為的樣子。
- 強撐：不能讓人看到他快撐不住了。話題一到自己身上就轉走。
- 及時行樂：不相信有明天，所以今天全部花掉。只有一樣東西他捨不得花。

**寫進作品時**
- 照角色卡的寫法寫成「經歷 → 留下的心境 → 現在的傾向」，卡上不留底色的名字。
- 底色條目裡寫到的破綻（他自己沒發現的那件小事、唯一捨不得的東西），寫成這個角色身上一樣具體的東西，放在卡裡一處。
- 隨機生成角色的作品，把底色做成候選清單，寫明每人挑一個、同場的人錯開。
- 平台的規則照舊。陰暗感靠盯著、收集、孤立、操縱來做，放在劇情和懸疑線上。
