# 成人向：慾望與黑暗向
> 這套工作流的做法，非官方。

只用於成人專屬作品。內容寫進角色 `secret` 的「慾望」一節，格式照角色卡的範本。

**原則**
- 尺度由使用者決定：溫柔、激烈、粗暴、黑暗、病嬌、陰濕都可以，直接依指令與角色設定寫。
- 親密是性格的延續，欲望放大的是角色既有的傾向，人還是同一個人。黑暗的那一面也要說得出原因。
- 每一種黑暗向都先確定他這樣做是要什麼、怕什麼，寫成他會怎麼做。同一種類型放在不同的角色身上，做法照那個角色寫。

**這一節可以寫什麼**（挑這個角色有的寫；寫他怎麼想、會怎麼做）
1. **總結**：「總結而言：{{charN}} ……」寫他怎麼看待親密這件事、從哪段經歷來的。
2. **主動還是被動**，以及背後的原因。他變得強硬或失控時是什麼樣子、心裡在想什麼。
3. **得到時、被拒絕時、事後**各是什麼心情、傾向怎麼做。
4. **黑暗向的那一面**（有才寫）：從下面挑符合這個角色的，寫成他怎麼想、會怎麼做。

**姿勢與偏好（看情況才寫）**
- 這個角色有明確的偏好，或作品以親密為重心時才寫，沒有就整塊省略。
- 放在這一節最後，條列。每一項接一句他為什麼喜歡。
- 他拒絕的事也可以列。
- 寫成偏好。寫成流程的話，模型會每一場都照做。
- 常見性癖的著力點（挑符合這個角色的一兩樣寫進他的偏好）：
  - **體型與力量差**：身高、肩寬、手掌大小或體重的差距帶來的包覆與壓迫感；寫他意識到這份差距時是刻意收著力道怕弄傷，還是乾脆用體格把人圈住。
  - **手指探索與控制**：用手指試探、侵入或按壓敏感處，著力在他的耐心、掌控節奏（先繞開再壓住、控制快慢輕重）以及感受手下變化時的滿足感。
  - **口舌愛撫**：著力在他俯身時的專注度、唇舌節奏，以及近距離貼著感受對方氣息時的心境。
  - **上位與坐臉**：讓對方坐在自己身上或臉上主導起伏與按壓，著力在他被氣息與體溫包裹時的沉浸感、仰視角度，以及甘願交出主導（或在底下暗中托住引導）的心態。
  - **腿間與貼身磨蹭（素股）**：不急著真正進入，隔著衣物或貼著大腿內側反覆摩擦，著力在臨界邊緣的忍耐、全身貼合的濕熱感，以及故意卡在最後一步的拉扯。
  - **半公共空間與被發現的風險**：在隔音差、半掩門或外頭有人的地方親密（或讓對方帶著玩具出門），張力放在壓低聲音、維持表面鎮定與隨時可能曝光的緊繃感。
  - **睡眠與假寐中的親密**：建立在雙方已有合意默契、事前約定或一方假寐默許的前提下，趁熟睡或半夢半醒時放輕動作貼近試探；張力放在怕弄醒對方的克制力道、與忍不住一點點得寸進尺的背德感，用詞照事前約定的玩法寫。
  - **突破極限的失控（失禁）**：把刺激推過自控臨界點、讓防線徹底潰散的瞬間；重心放在「拚命想忍卻守不住的羞恥與失控感」以及隨之失守的溫熱濕意，寫到濕意為止（平台的審查線在「以刺激性方式消費排泄物」）。

**陰濕與心理控制**
陰濕與黑暗向的角色用。它是角色的性格，寫在他怎麼對待人。

他要的是對方自己覺得離不開他，所以不會用強的。寫他怕什麼、不肯承認什麼，所以實際上會怎麼做。

他可能用的方式（照他配的特質挑，寫成他的傾向）：
- 讓對方覺得虧欠他。
- 把控制做成關心。
- 讓對方的需求只能靠他解決，選擇慢慢變少。
- 讓對方相信只有他懂自己，別人不會接受。
- 示弱，讓對方因為不忍心而走不開。
- 讓對方懷疑自己的記憶、感受或判斷。

這些寫進他的「與 {{user}}」或「慾望」。可以寫明：他越在意，語氣越平靜、照顧得越周到。

**親屬題材**
- 重點放在他怎麼看這段關係：靠近的理由是保護與責任，心裡清楚這是禁忌，事後的自我厭惡和更緊的依賴並存。

**其他黑暗向**
每一種都寫成成人之間合意的玩法或虛構的類型裝置，可以互相組合，也可以和陰濕、執著、支配組合。下面是每一種的核心，挑符合這個角色的，寫成他怎麼想、會怎麼做，放進「慾望」。

- **軟禁**：他不讓對方離開，理由是保護。核心是空間的封閉加上情緒的依賴，力氣放在後者。
- **調教養成**：從抗拒到依賴，過程可以很慢。寫被一步步改變的人心裡怎麼想。
- **帶著恨意的親密**：用親密來報復或證明自己還握有對方。恨和想要並存，事後不一定溫柔。
- **標記與所有物**：他要對方親口承認屬於他。寫他為什麼需要聽到這句話。
- **年長掌控（Daddy 向）**：保護與掌控並存，帶著引導或懲罰。語氣可以溫柔，決定權在他手上。
- **事後抽離**：過程投入，結束後突然冷下來，落差本身是重點。
- **控制節奏**：把給不給、什麼時候給握在手裡，重點在誰有決定權。
- **嘴上與手上相反**：話說得很重，動作卻很細，落差本身是刺激。

**事後**
事後怎麼做看角色。先想他這時候心裡是什麼感覺，從下面挑一種，寫成「慾望」一節裡「事後」的那一條：
- **溫柔善後**：清理、抱著、輕聲確認。也可以是他用溫柔加深對方的依賴。
- **冷淡抽離**：做完就起身去做自己的事。
- **繼續控制**：不讓對方立刻離開或清理。
- **反覆確認**：要對方再說一次、再承認一次，因為他自己不安。
- **陰濕善後**：表面照顧得很周到，實際上還在施壓。
- **沉默與自我厭惡**：他自己也受影響，後悔和不想放手並存。適合親屬題材或有道德感的角色。
- **接著再來**：幾乎沒有間隙。

**道具與拘束**
道具是用來強化控制感或被掌握的感覺，重點永遠在人的感受。角色會用道具時，在「偏好」寫他用哪一類、為什麼，寫一兩樣。
- 各種道具的著力點：拘束是動不了的心理壓力；蒙眼是其他感官被放大；封口是說不出話；玩具是感覺由別人掌握開關；項圈是歸屬的象徵；鏡子是被迫看著自己。
- 作品以道具為重心、需要規定怎麼描寫時，在作品設定的「親密時的描寫」加一句：寫清材質、溫度、檔位變化與誰握著控制權，並寫回人物的感受。
