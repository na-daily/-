# 開放世界怎麼寫
> 這套工作流的做法，非官方。

玩家自己決定去哪裡、做什麼的作品用這一份。世界的五件事先定好，再照這一份把每個地方和世界的變化寫出來。

## 世界要答得出這五件事
1. **能去哪裡**：有哪些地方，地方之間怎麼移動、要多久、要帶什麼或付什麼。
2. **每個地方碰得到什麼**：人、敵人、物資、會發生的事。
3. **玩家做了事，哪裡會變**：打倒了誰、拿走了什麼、幫了哪一邊，之後那個地方變成什麼樣。
4. **玩家離開的時候，世界自己怎麼變**：哪些事會照自己的步調往前走。
5. **可以往哪幾個方向發展**：列出好幾條，每一條都走得下去，走哪一條由玩家決定。

## 每個地方寫這六樣
寫玩家走進去實際會碰到的東西，六樣都寫。
1. **樣子**：從外面看是什麼樣、裡面怎麼分區、哪裡連到哪裡。
2. **拿得到什麼**：物資、情報、能用的設施。
3. **遇得到誰**：住在這裡的一般人怎麼過日子、能交涉的領頭人是誰、他要什麼。
4. **有什麼危險**：敵人的種類和強弱、環境本身的危險。
5. **這裡的規矩**：誰說了算、什麼行得通、什麼會惹上麻煩。
6. **會怎麼變**：這一區的狀態升一級或降一級時，上面五樣各變成什麼。

同一類地點共用的結構（每個據點都有的門口、倉庫、住處）寫一次通用的，各個地點只寫自己特別的地方。

## 內容放在哪
| 內容 | 放哪 |
|---|---|
| 世界的概述、各區一句、移動的規則、世界怎麼變的規則 | 作品設定 |
| 一個地方的完整內容（上面六樣） | 地點章節：一個地方一章，標題用地名，進行模式用自由移動。玩家選章節就是移動到那裡 |
| 只在做某件事時才用到的內容（交易、建設、某個角色的專屬內容） | 功能章節：一件事一章，做完切回地點章節 |
| 每個地方、每個勢力與領頭人的濃縮版 | 設定集，關鍵字用地名與人名 |
| 玩家現在在哪、各區的狀態、據點、物資、探索的進度 | 變數 |
| 遊戲中才生成的人 | 通用卡加變數 |

章節是平鋪的，一次只有一章在場；設定集是疊加的，提到幾個就進來幾條。所以完整內容放章節，濃縮版放設定集，兩邊講的是同一件事時用同一個說法。

## 世界怎麼變
- **變化綁在看得見的事件上**，一次加減一級：某件事發生在哪一區，那一區的狀態在那一則升一級；玩家解決了那一區的頭目，降一級。
- **每一條發展方向寫成一條會動的線**：它現在走到哪一階、什麼事會推它前進一階、每一階世界多出什麼。幾條線各自走，互相影響的地方寫出來。
- **藏起來的內容用探索的進度開啟**：進度累計到某個數時切進揭開它的那一章。內容只放在那一章。
- **成長綁在事件上**：打倒哪一級的敵人、拿到哪樣東西、完成哪件事之後升一階。能力在戰鬥以外的用途寫一句方向，讓模型照場面發揮。

## 人和據點
- **主要角色是世界裡的一個人**。他的事寫在他的角色卡，世界的設定寫世界。
- **各區的人分兩層寫**：一般人怎麼過日子寫在地點章節；能交涉的領頭人各有一條設定集，寫他是誰、要什麼、怎麼對待外來的人。
- **據點的位置交給玩家選**。設定寫各類地點當據點時差在哪：防得住哪一級的敵人、離物資多遠、附近有誰。

## 自查
- 每個地方的六樣都寫了嗎？每一句都是玩家走進去會碰到的東西嗎？
- 完整內容在章節、濃縮版在設定集，兩邊對得上嗎？
- 世界的變化都綁在看得見的事件上嗎？
- 發展方向有好幾條、每一條都寫了現在到哪一階嗎？
